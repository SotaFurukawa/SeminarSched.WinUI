# v0.19.0 (beta)

Status: Draft Release。新機能を含むためminorを上げ、patchを0へ戻してv0.19.0とした。

## 新機能

- **探索方針の並び替えをドラッグでも操作可能に**: 「①設定」「⑤時間割自動作成」の探索方針一覧を、
  従来の▲▼ボタンに加えて、行を直接ドラッグ（スライド）して並び替えられるようにした。
- **ライセンスの解除**: 「設定」画面に「ライセンスを解除」ボタンを追加した。動作確認用途も兼ねて
  おり、解除すると次回起動時に再度プロダクトキーの入力が必要になる。
- **⑤時間割自動作成の探索方針の一時変更が、ページを離れても保持されるように**: 以前はラジオ
  ボタンで値を変更した後に別ページへ移動すると内容が消えていた。ウィンドウを閉じるか、
  プロジェクトを切り替えない限り、入力内容をセッション内で保持するようにした。

## 対応内容（UI調整・不具合修正）

- **「設定」画面**: 「アップデートを確認」ボタンを見出しに近づけ、「ライセンス」欄にも同じ
  レイアウト（見出し＋ボタンが同じ行）を適用した。
- **時間割編集**: 日別グリッドの講師名見出しを、各列の中央に表示するようにした（以前は左寄り）。
- **ホーム画面**: 「Excelで基本情報を編集」と「編集した内容を反映」の間の矢印を、プレーンな文字
  からWinUI標準のアイコンに変更した。
- **「講師指導可能科目」タブ**: 講師・科目・保存ボタンと同じ行に、指導可否の選択（指導可能／
  指導不可の2択、既定は指導可能）を移動した。以前はチェックボックスが別の行にあった。
- **「通常授業担当設定」タブ**: 「1対1必須」チェックボックスを、生徒・科目などと同じ行に移動した。
- **時間割編集「複数コマ・複数講師の出勤可否を一括設定」を削除**: ③アンケート取込の「可用性の
  手動編集」と用途が重複していたため削除した。

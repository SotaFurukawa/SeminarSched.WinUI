# v0.28.0 (beta)

Status: Draft Release。日別グリッド編集・自動作成・出力xlsxに関する新機能6件を追加するminor。

## 変更内容

- **日別グリッド編集の日付の左右に、前後の授業日へ切り替える矢印ボタンを追加した**: 「◀」「▶」を
  押すと、カレンダー上の前後の日ではなく、実際に開校日として登録されている前後の授業日へ直接
  切り替わる。
- **日別グリッド編集で、未配置の受講希望をドラッグしている間、その生徒がアンケートで出席不可に
  している時間帯のコマに禁止マーク（🚫）と「(生徒出席不可)」を表示するようにした**: 既に出勤不可
  （グレー表示）のコマには重ねて表示しない。ドラッグしてそのコマへ置こうとした場合は、引き続き
  ドロップ自体は可能で、「生徒がアンケートで出席不可にしています。」という具体的な警告を確認した
  上で配置できる（従来は生徒・講師どちらが原因か分からない共通の文言だった）。
- **時間割自動作成に「既に配置済みの授業は動かさない（未配置のみを自動作成する）」チェックボックスを
  追加した**: CPU使用率の説明の下に配置。オンにすると、手動配置・事前確定・ロック済みのコマだけで
  なく、前回までの自動作成で配置済みのコマもすべて固定扱いにし、まだ配置されていない受講希望だけを
  対象に自動作成する。設定はCPU使用率の制限設定と同様に機体ごとに保存される。
- **出力xlsxの生徒配布用・講師配布用（全体時間割を除く、生徒ごとにシートが分かれているもの）で、
  1行目の高さを50にし、「指定範囲外」「休校日」のセルを日ごとの個別結合ではなく、同じ種類が
  横に連続する区間ごとにまとめて1つのセルへ結合するようにした**: 同じ文言が隣接する列へ重複して
  表示される問題を解消した。
- **講師配布用のxlsxで、生徒が受講する科目が2科目の場合はG5:H5・G6:H6へ、3科目以上の場合は
  3列ずつ左へ追加していく形で「科目＋通常授業担当講師」の欄を追加した**: 例えば3科目の場合は
  D5:E5・D6:E6・G5:H5の3箇所に表示される。生徒配布用（講師名を出さない版）には表示しない。
- **全体時間割で、日と日の境目に白い縦線を入れるようにした**: 日付行は従来と同じ太さ、実際の
  コマが並ぶ3行目以降は従来の2倍の太さ（Medium）にし、日と日の境目を見分けやすくした。

## 検証について

既存の全テスト（計252件）がすべて通過することを確認済み。加えて実機（dev-run）で、①日付の矢印
ボタンで前後の授業日へ正しく切り替わること、②未配置の受講希望をドラッグすると、生徒が出席不可の
コマ（出勤不可のグレーのコマを除く）に禁止マークが表示され、実際にそこへ置こうとすると
「生徒がアンケートで出席不可にしています。」という警告が出た上で配置可能なこと、③新しい
チェックボックスが表示・保存・ページ遷移後も保持されることを確認した。出力xlsxについても、
①生徒配布用・講師配布用の実ファイルで1行目の高さが50になっていること、②指定範囲外のセルが
複数列にまたがる1つの結合セルになっていること、③講師配布用で2科目・3科目それぞれの生徒の
実ファイルでG5:H5・G6:H6、またはD5:E5・D6:E6・G5:H5の結合と内容を確認し、生徒配布用には
表示されないことを確認した。④全体時間割の実ファイルで、日付行・コマ格子行それぞれの日の境目の
罫線が白色で、コマ格子行側がMedium（2倍の太さ）になっていることを確認した。

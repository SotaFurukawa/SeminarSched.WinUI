# v1.4.0

Status: Release

## 変更内容

- 「2 アンケート作成」に、新しいオプション「中学受験と中学受験以外を分ける」を追加した
  （既定はオフ＝現状維持）。
  - オフ（既定）: 今まで通り、生徒用フォームの小学校ページで「算数（中学受験）」
    「算数（中学受験以外）」（国語も同様）を別の選択肢として選ばせる。
  - オン: 小学生の回答者にだけ、科目選択の前に「中学受験をしますか？（必須）」という
    専用の質問を追加する。算数・国語の選択肢は中学受験の有無で分けず「算数」「国語」の
    単一選択肢にする。「中高一貫などで他学年の授業を受講される」ページの選択肢は
    対象外で、常に今まで通り分割済みの選択肢のままになる。
  - どちらの設定でも、アプリへ取り込まれる受講希望の内容（整形済み回答シートの列・値）は
    完全に同じになる。復元処理はGoogle Apps Script側の回答正規化（フォーム送信時に動く
    `writeCompactStudentResponse_`）で行っており、受講希望アンケート取込み
    （`CourseSurveyImportService`）側の変更は無い。
  - 詳細は`docs/adr/0010-questionnaire-entrance-exam-question-toggle.md`を参照。

## 調査結果の報告（コードの変更は無し）

クライアント側で「生徒用フォームに必要な小学校・中学校・高校の使用中科目が不足しています。
①の科目を確認してください。」という警告が出た件を調査した。

- `共通名簿Excel`（生徒・講師_基本情報.xlsx）自体は科目26件すべてが有効で、小学校・中学校・
  高校の3校種をすべて含んでおり、ファイル自体に問題は無かった。
- アンケート作成（`QuestionnaireKitService.GenerateAsync`）は、共通名簿Excelやroster.dbを
  直接読むのではなく、**アンケートを作成したプロジェクト自身のDB**から有効な科目を読み込む
  仕様になっている。このロジックはこのセッションで行った過去の修正（v1.2.0〜v1.3.1）の
  影響を受けておらず、regressionではないと判断した。
- 最も可能性が高い原因は、共通名簿Excel側に科目を追加した後、そのプロジェクトへ「共通名簿を
  取込む」操作がまだ行われていない（または科目追加前に作成した古いプロジェクトのままになって
  いる）ことである。該当プロジェクトを開き、「0 基本情報設定」または「1 プロジェクト設定」の
  科目取込み操作を行えば解消する見込み。
- 警告文中の「①」という案内は、v1.2.0で科目タブが「0 基本情報設定」へ移動した今では古い
  表記のままになっている。今回は指摘された内容に絞り、この文言自体の修正は行っていない。

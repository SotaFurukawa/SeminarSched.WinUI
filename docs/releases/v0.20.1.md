# v0.20.1 (beta)

Status: Draft Release。UI調整・不具合修正のためpatchを上げてv0.20.1とした。

## 対応内容（UI調整・不具合修正）

- **左ナビゲーションの番号表記を統一**: 「①設定」「⑥出力」のような丸数字と、「1.1 生徒」
  「3.1 集団授業クラス」のような小数点付き数字が混在していたため、丸数字（①〜⑦）をすべて
  素のアラビア数字（1〜7）へ置き換え、サブ項目の「X.Y」表記と同じ書体で統一した（「1 設定」
  「1.1 生徒」〜「1.8 出力設定」「2 アンケート作成」「3 アンケート取込」「3.1 集団授業クラス」
  「3.2 集団授業の受講登録」「4 時間割編集」「5 時間割自動作成」「6 出力」）。ページタイトルや
  他画面からの参照文言（「①設定」タブで…など）も同様に置き換え、手順の順序を示す番号自体は
  引き続き表示している。
- **「講師指導可能科目」の科目見出しが、長い科目名ではみ出す不具合を修正**: 見出し2段目
  （科目名）の高さが固定値だったため、「算数（中学受験以外なら可能）」のように折り返すと
  2行を超える科目名が上下で欠けて表示されていた。実際の科目名を列幅に合わせて仮測定し、
  最も高さを要する科目に合わせて見出し行の高さを動的に決めるようにした（短い科目名しか
  ない場合は従来どおりの高さのまま）。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

## 検証について

一時的な別パッケージIDの実機ビルドで、①左ナビおよびサブ項目の番号表記が統一されていること、
②「算数（中学受験以外なら可能）」等の長い科目名が見出しからはみ出さず全体表示されること、
の両方をスクリーンショットで確認してから出荷した。検証用のテストパッケージ登録は確認後に
削除済み。

このversionのGitHub ReleaseはDraftとして作成する。

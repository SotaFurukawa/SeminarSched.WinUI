# v1.5.2

Status: Release

## 変更内容

v1.5.0で追加した「他学年を含む」ページの科目選択肢への学校区分付記（例:「物理（高校）」）を
差し戻した。

実際にデモでフォームへ回答したところ、以下のような問題が発生した。

> 山下太郎は、高校生ですが、中学生の理科を受けたいとなったときに、学校区分が「高校」、教科が
> 「理科（中学校）」のようになっています。以前までは、学校区分「中学」、教科が「理科」のように
> なっていたはずなので、そうなるように修正してほしい。アンケートの中身は変えない。

「他学年を含む」ページは、「学校区分」という独立した項目で「受けたい科目がどの学校段階のもの
か」を明示的に回答させる設計になっている。科目名自体にも学校区分を付記したことで、学校区分を
2か所で尋ねる形になってしまい、回答者が「学校区分」には自分自身の学年を、科目名は付記付きの
ものを選んでしまう、という矛盾した組み合わせが実際に発生した。

対応として、v1.5.0の付記（科目選択肢の生成、および取込み側の付記パーサー・フォールバック）を
完全に差し戻し、「学校区分は明示的なドロップダウンだけで判定し、科目名には含めない」という
以前の設計へ戻した。v1.5.1で見つけたもう1件の不具合修正（学校区分だけ埋まった未使用の教科目を
正しく無視する）は付記と無関係なため、そのまま維持している。

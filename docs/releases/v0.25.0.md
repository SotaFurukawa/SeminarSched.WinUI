# v0.25.0 (beta)

Status: Draft Release。生徒・講師一覧への空きコマ許可列追加という新機能のためminorを上げて
v0.25.0とした。

## 変更内容

- **生徒・講師一覧に「空きコマ許可」列を追加した**: これまで編集時にしか確認できなかった
  「空きコマ許可」を、一覧上で「あり」/「なし」として常に確認できるようにした。
- **受講希望一覧（アンケート取込ページ）の列幅を改善した**: 生徒氏名・科目名・通常担当講師・
  第1〜3希望の6列を固定幅から可変幅（`Width="*"`）に変更し、ウィンドウの余白を使って表示できる
  ようにした。必要回数・優先度・1対1・最大連続上書き・空きコマ上書きの5列は、値が短いため従来
  通り固定幅のまま維持している。ウィンドウが狭い場合の横スクロールは引き続き有効。
- v0.24.0でリリースした`CentralVersion_IsCurrentBetaVersion`テスト（`Directory.Build.props`の
  バージョン文字列を検証）が、バージョン更新時に値を追従させ忘れていたため失敗していたのを
  修正した（期待値を`0.25.0`へ更新）。

## 検証について

既存の全テスト（計252件）がすべて通過することを確認済み。加えて実機（dev-run）で、①生徒・
講師一覧に「空きコマ許可」列が表示されること、②講師の「空きコマ許可」をオンへ変更→保存→
一覧へ「あり」として反映されることを確認した。受講希望一覧の列幅改善は、ウィンドウを最大化した
状態で各列の文字（学年・科目名等）が途中で切れずに表示されることをスクリーンショットで確認した。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

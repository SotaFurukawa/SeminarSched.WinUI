# v0.13.4 (beta)

Status: Draft Release。ユーザー報告「インストール中のエラーです。先ほどと同じです」への対応。
bug fixのためpatchを上げてv0.13.4とした。

## 対応内容

- v0.13.3のインストール失敗（エラーコード1）を、この開発機で`Add-AppxPackage`・Setup.exeの
  サイレント実行の両方で再現を試みたが、直近で確認した限りではこの開発機では再現しなかった
  （開発機で残っていた`dotnet run`由来の未署名パッケージ登録を削除した上で、署名済み.msixの
  インストールが正常に完了することを確認済み）。
- 根本原因を切り分けられるよう、インストーラのエラー表示を改善した。従来はSetup.exeのエラー
  ダイアログに数値の終了コードしか表示されず、実際にWindowsが返した失敗理由が分からなかった。
  `installer\Install-Package.ps1`が失敗理由を`%TEMP%\SeminarSched.WinUI-install-error.log`へ
  書き出すようにし、Setup.exe側のエラーダイアログにもこのログファイルのパスを表示するようにした。
- もし今回も同じエラーが出た場合は、お手数ですが上記ログファイルの中身を共有してください
  （このversionでビルドし直したSetup.exeでないと、この改善は反映されません）。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

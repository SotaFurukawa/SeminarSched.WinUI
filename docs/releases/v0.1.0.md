# v0.1.0 (beta)

Status: Draft Release。Python版v1.9.5の全利用者向け機能をC# + WinUI 3へ移植する開発サイクルの最初の区切り。最適化の探索品質（辞書式目的の完全実装・複数戦略・トーナメント探索の実行速度調整）は次段階へ継続する前提で、それ以外の①〜⑥業務flowはPython版とほぼ同等の内容まで実装した。

## ハイライト

- ①設定〜⑥出力の6段階業務flowを、project作成からExcel/PDF出力まで一通り実行できる状態にした。
- SQLiteを使ったproject管理（新規作成・open・close・複製・自動backup・世代管理・復元）を、Python版と同様に`%LocalAppData%`配下で一元管理するよう統一した。
- OR-Tools CP-SATによる時間割自動作成、ドラッグ&ドロップ手動編集、Undo/Redo、講師出勤可否の一括編集を実装した。
- 全体時間割・生徒配布・講師配布（学年順・講師別）のExcel/PDF帳票をPython版のレイアウトに沿って生成し、A4印刷時の収まりを数値検証した。
- 共通基本情報Excelに名前選択dropdownを追加し、講師対応科目・受講希望のID/コード入力を名前選択だけで完結できるようにした。
- Google Formsアンケート作成kit（生徒・講師勤務可能日時・講師指導可能科目の3フォーム）を1つのApps Scriptから生成できるようにした。
- Windows配布方針をMSIXサイドロードに確定し、署名・証明書信頼までの手順を実機検証した。

## ①〜⑥ 業務flow別の実装状況

### ホーム・project管理
- 年度・講習区分・期間を指定した新規project作成、既存project open・close、複製、最近使ったproject履歴（最大10件・「表示しない」での非表示化）。
- SQLite schema v2・v1→v2自動migration・整合性確認。
- project open毎の自動backup（直近5世代を`%LocalAppData%\SeminarSched.WinUI\Workspace\Backups`へ集約管理）、手動backup作成、確認dialog付きrestore。
- Python版projectなど`ApplicationMetadata`テーブルを持たないファイルを開こうとした際のクラッシュを修正し、案内メッセージ表示に変更。
- 新規作成・open・複製はfolder選択dialogを残しつつ開始folderを`Workspace\Projects`へ固定。バックアップ・出力・Googleフォームkitはdialogを廃止し固定folderへ自動保存するよう統一。

### ①設定
- 生徒・講師・科目の追加・一覧・編集・使用停止、検索box、ID自動採番。
- 講師対応科目の個別設定・複数講師×複数科目への一括設定（指導可否・備考）。
- 通常授業の担当優先度設定、受講希望の個別登録・編集・削除（必要授業回数・希望講師・1対1必須・上書き項目・備考）。
- コマ設定（drag&dropでの並べ替え）、開校日・休校日の複数選択一括設定（備考付き）。
- 共通基本情報Excelの5シート出力・検証取込み・名前選択dropdown。

### ②アンケート作成
- 生徒用・講師用（勤務可能日時）・講師指導可能科目用の3つのGoogle Formsをまとめて生成するApps Scriptとreadmeを固定folderへ出力。

### ③アンケート取込み
- CSV（UTF-8/CP932/BOM自動判定）・XLSXの2ファイル選択、全行検証、SHA-256再確認、単一transaction反映。
- 可用性形式・簡易形式（必要回数・勤務不可）双方の追加/変更/変更なし件数のdiff表示、削除候補の明示確認。
- 生徒・講師の可用性を複数日付×複数コマへ一括適用する編集UI（transaction保護、一部競合時は全体rollback）。

### ④固定授業
- 固定Assignmentの追加・解除、資格・重複・1対1・必要回数の検証。

### ⑤時間割自動作成・編集
- OR-Tools CP-SATによる自動作成（5段階の品質profile、hard constraint検証）。
- 日付選択付きグリッド編集、ドラッグ&ドロップでの手動配置・移動、ロック切替、講師出勤可否の個別・一括編集。
- グリッド見出し行・列の固定表示（scroll時も講師名・コマ名が常に見える）。
- Undo/Redo（自動作成・手動編集すべてをスナップショットで復元、アプリ内メモリのみ）。

### ⑥出力
- 全体時間割（週単位grid、出勤不可コマのgray表示）・生徒配布・講師配布（学年順・講師別）のExcel/PDF出力。
- 講師別folder内に個別Excel/PDFファイルを生成（担当一覧は通常担当分→講習担当分の2区分）。
- 未配置一覧・通常担当不足の診断出力。
- 出力後、生成ファイル一覧からOSの既定アプリで直接開ける確認UI。

### 共通基盤
- 操作ログ（`%LocalAppData%\SeminarSched.WinUI\logs`、14日保持、個人情報を含まない）。
- Windows配布はMSIXサイドロード方式に確定（署名・証明書信頼手順を実機確認済み）。

## 既知の未実装・保留

- 最適化の辞書式目的（生徒週偏り・担当講師分散・講師稼働率公平性など）の完全実装、greedy初期解・複数探索戦略、実行速度プリセット（30/120/600秒）はv0.2.0以降で継続する。
- 集団授業機能はPython版v1.9.5でもUI停止中のため、本版でも同様に未実装。
- Google Formsの生回答（列名がGoogle標準のまま）を③取込みへ直接読み込む自動列mappingは未実装。取込み時は生成済みCSV/XLSX形式を利用する。
- `.msix`のダブルクリックインストール自体の最終確認はユーザー環境での実施待ち（証明書信頼手順は実機確認済み）。

# v0.3.1 (beta)

Status: Draft Release。v0.3.0公開後、ユーザーから実機スクリーンショット付きで受け取った詳細な不具合報告一式への対応（TimePickerの全廃、①コマ並び替えの保存漏れ、画面遷移での状態消失、⑥出力xlsxの書式統一）と、その後追加で試みた実験的機能（生徒配布・講師配布xlsxを校舎ごとにカスタマイズできる「デザイン設定」テンプレートシート）をまとめた区切り。「個人情報に関わる重大な問題が発生するとき以外は勝手に進めてよい」との明示的な自律作業の許可を受け、5時間程度の間に対応した内容。

## ハイライト

- ①コマ設定・3.1集団授業クラスの時刻入力を、不具合の多かったWinUI標準`TimePicker`から、時・分別々の`NumberBox`へ置き換えた。分まで正しく表示され、確定操作も不要になった。
- ①コマ設定の一覧をドラッグで並び替えても保存されず画面遷移で元に戻る不具合を修正した。
- 全11ページに`NavigationCacheMode="Required"`を設定し、画面遷移をまたいでも各画面の状態（⑥出力の生成済みファイル一覧など）が保持されるようにした。
- ⑥出力で生成するxlsxの書式をユーザー指定に合わせて全面的に統一した（科目名の略称統一、全体時間割のコマラベル配置、生徒配布・講師配布ページのフォント/色/罫線/列幅など多数）。
- 集団授業クラスに科目（自由入力）を追加した。
- 実験的機能として、生徒配布・講師配布xlsxに校舎側で編集可能な「デザイン設定」シートを追加し、次回出力時に編集内容を自動的に読み戻して反映する往復編集の仕組みを試作した。

## 主な変更点

### ①コマ設定・3.1集団授業クラス
- 開始・終了時刻の入力を`TimePicker`から時・分の`NumberBox`ペアへ置き換えた。ユーザー報告にあった「分が表示されない」「確定ボタンが要る」「ドラムロールが不思議な場所に出る」はいずれもWinUI標準`TimePicker`のflyoutに起因すると判断し、flyout自体が存在しない`NumberBox`へ根本的に置き換える形で解消した。
- ①コマ設定の一覧をドラッグ&ドロップで並び替えても、`ListView`の`DragItemsCompleted`が保存条件を誤って判定しており永続化されていなかった不具合を修正した。
- 集団授業クラスに「科目」欄（自由入力）を追加した。

### 画面遷移での状態保持（全画面共通）
- Home/About/Settings/Setup/Questionnaire/Import/集団授業クラス/集団授業受講登録/時間割編集/自動作成/出力の全11ページへ`NavigationCacheMode="Required"`を設定し、画面を離れてもDBに保存されない一時的な表示状態（⑥出力の結果ファイル一覧など）が保持されるようにした。

### ⑥出力xlsxの書式統一
- 未配置一覧・警告一覧の科目名を、他の帳票と同じ略称（例:「数」）表記に統一した。
- 全体時間割（季節講習時間割）のコマ・時刻ラベルを、日付ごとの繰り返しから週の先頭（A列）へ1回だけ配置する形に変更（列幅もA=45px・B以降=30pxへ統一）。
- 生徒配布・講師配布（1生徒1ページ）の書式を全面刷新: 全マス中央ぞろえ、学年欄の右揃え/左揃え、氏名フォントサイズ14、タイトル行をBIZ UDPMincho Medium・黒地白文字、本文フォントをHG丸ゴシックM-PROに統一、月/日/学力テスト行の塗り色指定、曜日・日・教科名のフォントサイズ9、月見出し11、列幅をA=54px・B=96px・C〜I=64pxへ変更、カレンダー部分の格子罫線など。

### 実験的機能: 「デザイン設定」テンプレートシート
- 生徒配布・講師配布（学年別・講師別）xlsxの「講習欠席一覧」シートの直後・各生徒シートの直前に、書式12項目（フォント名・サイズ・色）を編集できる「デザイン設定」シートを追加した。
- 校舎がこのシートをExcel上で直接編集して保存すると、次回以降の⑥出力時に自動的に読み戻して反映される（出力先フォルダ内の直前の出力から読み取り、シートが無い・値が壊れている場合は既定値へフォールバックし、出力自体は失敗しない）。
- **この機能は「試してみて良ければ採用、微妙なら廃止」という前提の実験的な位置づけ。** 実機での見た目・操作感の確認結果次第で、正式採用するか元の固定書式に戻すかを判断する必要がある。

### その他
- 出力フォルダ名の一意化を秒単位からミリ秒単位に変更し、同一秒内に連続して⑥出力を実行した場合の潜在的な衝突を解消した。
- 最高品質（Highest）の自動作成が短時間で終わる件について、CP-SATソルバーが最適性を証明した時点で早期終了する既定動作であり、実機ログ（配置458件・未配置0件・約174秒）から見て改善の余地が無いことを証明した結果である可能性が高いと判断した（コード変更なし、調査のみ）。

## 既知の未実装・保留

- 集団授業の受講時間帯を④時間割編集・⑤時間割自動作成の制約（個別指導との二重予約回避）へは連携していない。
- 「デザイン設定」テンプレートシートは実験的機能であり、実機確認の結果次第で今後廃止・変更の可能性がある。
- v0.3.0以前のリリースノート記載の既知の未実装・保留事項は引き続き未対応。

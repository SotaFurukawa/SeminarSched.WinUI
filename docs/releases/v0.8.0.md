# v0.8.0 (beta)

Status: Draft Release。ユーザー要望「一時停止ボタンを作ってほしい。アプリの方に自動作成の部分に停止ボタンを作る」（checkpoint 99）への対応。新機能のためNext Version Ruleの既定に従いv0.8.0とした。

## ハイライト

- ⑤時間割自動作成の画面に「一時停止」ボタンを追加した。押すと、現在実行中の探索が終わり次第、次の探索を開始せずに待機する。もう一度押す（「再開」）と、そこから続きを実行する。
- CP-SATの探索そのものは実行中に瞬時に止めて後から続きから再開する、という機能が無いため、「次の戦略・次の延長パスを開始する直前の区切りでのみ止める」方式を採用した。要求してから実際に止まるまでには、実行中の1回分の探索時間だけタイムラグがありうる。
- 一時停止中でも「中断して現在の結果を採用」は引き続き機能する（一時停止は中断の代わりにはならない）。

## 主な変更点

### 一時停止／再開

- `OptimizationRunControl`に`RequestPause()`/`Resume()`/`WaitIfPausedAsync()`を追加。`ScheduleOptimizer.RunAsync`は、通常ステージの次の戦略を始める直前、および延長フェーズの次のパスを始める直前の、合計2箇所でこの一時停止を確認する。
- ⑤画面に「一時停止」ボタン（押すと「再開」に切り替わる）と、一時停止の状態を案内するInfoBarを追加した。現在の探索が終わるまでの「一時停止を要求中」と、実際に待機に入った「一時停止中」を区別して表示する。
- 経過時間・進捗パーセンテージの表示は、一時停止中は一時停止した瞬間の値のまま静止させ、再開すると違和感なく続きから動くようにした。

## 既知の未実装・保留

- 一時停止中も、名目時間・延長フェーズの各タイマー自体は実時間で進み続ける（一時停止していた時間を差し引く、という対応はしていない）。長時間一時停止した場合は、v0.7.6/v0.7.7で実装済みの「既定の時間を過ぎても継続する」延長機構がそのまま吸収する形になる。
- 品質プロファイル（`OptimizationProfileCatalog`）自体のさらなる見直しは保留中（ユーザーからの明示的な要望あり、実装するまで毎回案内する）。
- 今回の変更はUnitテストで検証済みだが、実機での「一時停止」ボタンの見た目・操作感の確認は未了。実機でご確認いただきたい。

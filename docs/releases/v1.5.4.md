# v1.5.4

Status: Release

## 変更内容

「設定」ページで「アップデートを行う」のボタンが、他の2つのボタン（ライセンスを解除・
アップデートを確認）と左端・右端が揃わずずれる問題を修正した。

「アップデートを行う」ボタンだけ、状態文言（ダウンロード中…など）と同じ横並びのパネル内に
あったため、状態文言の長さぶんだけ開始位置がずれ、幅も他の2つのボタンと揃っていなかった。
他の2つのボタンと同じ列へ移し、3つのボタンが同じ列幅（最大幅へ自動的に揃う）を共有するように
して、左端・右端とも一致させた。

## 検証について

- `dotnet build`成功（警告・エラー0件）。
- 既存の全テスト、合計278件がすべて通過することを確認済み。
- レイアウトの見た目自体はUIの実操作が必要なため、この環境では実機確認ができていない
  （既知の制約）。

# v1.0.3

Status: Release（「生徒・講師基本情報を新規で作成」のExcelテンプレートについて、v1.0.2で見た目を
戻した後に残っていた自動入力まわりの不具合を追加で修正）。

## 変更内容

- **在籍チェック・生徒ID/講師IDの自動入力・氏名（確認）の自動入力が消えていた不具合を修正した**:
  v1.0.2で色・罫線は戻したが、以下の自動入力の仕組みがまだ復元できていなかった。実際に運用で
  使っている元のExcelファイルを参照し、同じ仕組みに戻した。
  - 在籍列を、文字列ではなく正しい真偽値（TRUE/FALSE）のセルにし、ドロップダウンで選べるようにした。
  - 姓を入力すると、生徒ID・講師ID列へ次に使える連番ID（例: S-0078）が自動的に入るようにした
    （非表示の補助シートから算出する数式。既存行のIDはそのまま変更しない）。
  - 氏名（確認）列は、既存行・新規行を問わず、姓・名から常に自動で組み立てるようにした。
  - 標準最大連続コマ数（既定値2）・空きコマ許可（既定値なし）・講師対応科目の指導可能（既定値はい）・
    通常授業の担当講師優先度（既定値3）・1対1必須（既定値いいえ）も、まだ値の無い新規行では
    自動的に既定値が入るようにした。
- **必須列（学年・最大連続コマ数・空きコマ許可・名前の選択等）に、誤った値を入力したあと空白へ
  戻せない不具合を修正した**: 入力規則が空白を許可していなかったため、誤入力後に削除しようとしても
  エラーで止まってしまっていた。すべて空白を許可するよう変更し、必須であることは黄色の背景色
  だけで示すようにした。
- **通常授業シートに、生徒IDの隣（3列目）へ「学年」列を追加した**: 生徒シートの学年を自動的に
  参照して表示する。通常授業を確認する際に、生徒の学年を別シートで確認しなくてもよくなる。

## 検証について

既存の全テスト（計263件）がすべて通過することを確認済み。生成したExcelファイルをClosedXMLで
読み戻し、在籍列の型・各数式の内容・入力規則のallowBlank設定・新しい学年列の数式が、実運用の
Excelファイルおよび参照実装（Python版）と一致することをプログラム的に確認した。実機Excelでの
目視確認は、この開発環境のスクリーンショット手段が意図しない画面を捉えてしまうため行えていない。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

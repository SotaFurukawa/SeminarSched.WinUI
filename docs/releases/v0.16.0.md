# v0.16.0 (beta)

Status: Draft Release。新機能のためminorを上げ、patchを0へ戻してv0.16.0とした。

## 新機能: 自動アップデート確認

- アプリ起動時に、週1回を目安に新しいバージョンが公開されていないかを自動で確認するように
  した。新しいバージョンが見つかった場合のみ、ダウンロードページを開くかどうかのダイアログを
  表示する（見つからない場合は何も表示しない）。
- 設定画面に「アップデートを確認」ボタンを新設した。押すと即座に確認を行い、「最新バージョン
  です」または「新しいバージョンが利用可能です」＋ダウンロードページを開くボタンを表示する。
  前回自動確認した日時も表示する。
- 確認は専用サーバーを立てずに、本リポジトリのGitHub Releases API（公開済みreleaseの最新版を
  返す無認証エンドポイント）を直接利用している。本リポジトリは
  [ADR 0006](../adr/0006-product-key-licensing.md)の経緯で既にpublicへ切り替え済みのため、
  追加の認証情報は不要。
- 設計判断の詳細は[docs/adr/0007-auto-update-check.md](../adr/0007-auto-update-check.md)を
  参照。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

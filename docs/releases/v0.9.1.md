# v0.9.1 (beta)

Status: Draft Release。ユーザー要望「全体時間割のレイアウトを少し変更します」（詳細な体裁指示、
checkpoint 105）への対応。既存の全体時間割Excelの体裁変更でbug fix/UI微調整相当のため、Next
Version Ruleの既定に従いv0.9.1とした。

## ハイライト

- 全体時間割Excelの週別シートのレイアウトを全面的に変更した。
  - 日付・講師名ヘッダーの背景色を紺色から黒へ変更。
  - 2行目の日付表示から年を削除し、日付部分のみ斜体、曜日部分は非斜体の混在書式に変更（フォント
    「MS UI Gothic」・サイズ18）。
  - 学年／講師名／生徒名／教科のフォントを「HGゴシックM」に変更（学年のみサイズ10、他はサイズ11）。
  - 講師名をコマごと（日に1回ではなく毎コマ）の先頭行へ記載するよう変更し、塗りつぶし無し・文字色黒
    にした。各コマの下部に空白行（高さ12px）を追加した。
  - 生徒氏名の行の高さを65pxに固定した。
  - 講習期間内の休校日に、専用の列（セル結合・黒塗り・白文字・縦書き・列幅25px・白線の外枠）を追加
    した。
  - A列の見出し「コマ」の文字を削除し、コマラベル部分をグレーで塗りつぶし、コマ名／開始時刻／∼／
    終了時刻を改行区切り・フォントサイズ9で表示するよう変更した。
  - 時間割データの入っている領域全体に格子（罫線）を適用し、シート全体を水平・垂直とも中央ぞろえに
    した。
- 上記のデータモデル変更（休校日を列として明示的に含める）に伴い、PDF版の全体時間割が休校日を
  「出勤予定なし」と誤表示しないよう、休校日には「休校日」ラベル（黒塗り・白文字）を表示する最小限
  の修正を行った（PDF側の本格的な体裁追従は今回の指示範囲外のため見送り）。

## 主な変更点

- `OverviewGridLayout.OverviewDay`に`IsClosed`を追加し、休校日を`Weeks`から除外せず専用の列として
  含めるようにした。
- `ExcelScheduleReportRenderer.WriteOverviewWeekSheet`を全面書き換え（1コマ3行→5行構成、休校日列、
  A列の再構成、行の高さ規則、ClosedXML RichTextによる日付部分のみ斜体化、フォント・色の変更）。
- `PdfScheduleReportRenderer.AddOverview`に休校日判定の最小限の追従を追加（回帰防止）。

## 既知の未実装・保留

- 品質プロファイル（`OptimizationProfileCatalog`）自体のさらなる見直しは保留中（ユーザーからの
  明示的な要望あり、実装するまで毎回案内する）。
- フォント「HGゴシックM」「MS UI Gothic」の実際の表示、行の高さ・休校日列の縦書き等の視覚的な体裁は
  この開発機では確認できないため、実機でのご確認をお願いしたい。特に「A列3行目より下を一律グレーに
  する」の解釈（2コマ目以降の講師名行位置が無地グレーになる）はユーザーの意図と異なる可能性がある。
- PDF版の全体時間割へ同等の体裁変更を反映するかどうかは未確認。必要であれば別途ご指示いただきたい。

# v0.21.1 (beta)

Status: Draft Release。v0.21.0のUI調整のためpatchを上げてv0.21.1とした。

## 対応内容（UI調整）

- **通知トーストの横幅を、左ペイン（タブバー）を除いたコンテンツ領域の幅に連動するよう変更**:
  以前はウィンドウ全体を基準に中央寄せの固定幅（最大480px）だったが、タブバーにかからない
  位置から右端近くまで（コンテンツ領域の幅よりわずかに狭い程度）広げ、ウィンドウのサイズや
  左ペインの展開・収納に応じて自動的に幅が追従するようにした。
- **通知トースト内の文字列を、アイコンの右側に左詰めで表示するよう変更**。
- **「Googleフォーム回答の取込」見出しのアイコンを、ナビゲーションの「3 アンケート取込」と
  同じものから、Googleフォームを連想させる専用アイコン（紫色のフォーム＋チェックマーク、
  オリジナル作成のSVG）へ変更**: ナビゲーションのアイコンと紛らわしいという指摘を受けた。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

## 検証について

一時的な別パッケージIDの実機ビルドで、①通知トーストの横幅がコンテンツ領域に連動すること
（ウィンドウを最大化した状態でも追従すること）、②文字列がアイコンの右側に左詰めで表示される
こと、③「Googleフォーム回答の取込」の見出しアイコンが新しいデザインで表示され、ナビゲーションの
アイコンとは異なるものであること、をスクリーンショットで確認してから出荷した。検証用のテスト
パッケージ登録は確認後に削除済み。

このversionのGitHub ReleaseはDraftとして作成する。

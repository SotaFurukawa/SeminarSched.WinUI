# v0.21.3 (beta)

Status: Draft Release。プロジェクト設定画面の小規模なUI調整をまとめてpatchを上げてv0.21.3とした。

## 変更内容

- **「1 設定」を「1 プロジェクト設定」に名称変更**: ナビゲーション・ページタイトル、および本文中の
  言及箇所（ホーム画面、時間割自動作成画面、Googleフォーム取込時の案内文）をすべて揃えた。
  歯車アイコンの「設定」（ライセンス・更新確認）は対象外。
- **生徒一覧に「最大連続コマ数」列を追加**: 学年の右側に表示し、編集フォームを開かなくても
  一覧上で確認できるようにした。
- **講師指導可能科目タブを表だけに簡素化**: 従来は表の上に講師・科目・指導可否・保存の入力フォームと
  備考欄があったが、表の○クリックで指導可否は直接切り替えられるため実質的に不要だった。
  備考の編集だけは他に手段がなくなるため、○セルの右クリック/長押し（RightTapped）で
  備考編集ダイアログを出す形に移した。
- **コマ編集：有効チェックボックスを保存ボタンより前に**: 従来は「保存ボタン→（次の行で）有効
  チェックボックス」という操作順だったが、有効チェックボックスを保存ボタンの直前へ移動し、
  自然な操作順（有効を確認してから保存）に揃えた。

## 検証について

対象の4画面すべてを実機（dev-run、既存のテストプロジェクトデータ）で操作して確認した：
ナビゲーション名称、生徒一覧の新しい列、講師指導可能科目タブが表のみになっていること、
○セルの右クリックで備考編集ダイアログが開くこと、コマタブの操作順。
既存の全テスト（Architecture/Domain/Application/Optimization/Infrastructure）がすべて
通過することも確認済み。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

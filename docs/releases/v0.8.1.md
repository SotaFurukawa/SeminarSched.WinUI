# v0.8.1 (beta)

Status: Draft Release。ホーム画面・「①設定」画面の文言・レイアウト・操作性についてユーザーから
まとめて指摘を受けた内容への対応（checkpoint 100）。bug fix・UI微調整のためNext Version Ruleの
既定に従いv0.8.1とした。

## 主な変更点

### ホーム画面（新規プロジェクト作成）

- 「一時SQLiteの作成と整合性確認に成功した場合だけ保存します。」の一文を削除した。
- 「1人の講師が同時に担当できる生徒数」の見出しを「一人の講師が同時に担当できる生徒数（既定は2人）」に変更し、既存の「集団授業の日程を考慮する」チェックボックスと連動させた。このチェックボックスがオフの間は変更できず（既定の2人に固定）、オフにすると自動的に2へ戻る。個別指導の既定運用（1対2）から外れた人数は、集団授業を行うプロジェクトでのみ意味を持つための対応。
- 説明文を「既定は1対2です。校舎によっては1対3・1対4等も運用されているため、必要に応じて変更してください。」から「一人の講師が担当する生徒の人数を設定できます。」へ簡潔化した。
- 「①設定」の「スケジュール設定」タブ・⑤時間割自動作成画面の同項目の見出しも同じ表記へ統一した（既定は2人）。

### ①設定 - 生徒・講師

- 生徒ID・講師IDは操作者が直接編集できないようにした（入力欄をグレーアウト表示）。「新規入力」を押すと、既存IDのうち最も大きい番号の次の番号があらかじめ表示される（保存時に採番し直すことはない）。氏名・学年（生徒の場合）のみを入力して保存すればよい。従来の「IDを自動採番」ボタンは不要になったため削除した。
- 生徒・講師それぞれの入力欄の上に「新規で通期の生徒（講師）を追加できます。ホームの「Excelで基本情報を編集」からでも追加できます。」という案内文を追加した。
- 講師の一覧も、生徒と同じ列（ID・氏名・状態）が揃った表形式で表示するようにした（従来は列の揃っていない単純な一覧だった）。

### ①設定 - 科目

- 科目の一覧を、生徒・講師と同じ列（順序・コード・科目名・略称・校種・状態）が揃った表形式で表示するようにした（従来は列の揃っていない単純な一覧だった）。

### ①設定 - 担当設定を2タブへ分割

- 「担当設定」タブを「講師指導可能科目」と「通常授業担当設定」の2つのタブへ分割した。
- 「複数の講師・科目へ一括設定」機能は削除した。
- 「講師指導可能科目」の表で、校種の並びを小学校→中学校→高校の順に修正した（従来は文字コード順のため中学校・小学校・高等学校の順になってしまっていた）。あわせて、科目名の列見出しに含まれていた「高校・」等の校種接頭辞を、既に列見出し（校種ごとのグループ見出し）で表示済みのため省いた（例:「高校・英語」→「英語」）。
- 「通常授業担当設定」の一覧表示から生徒ID・講師IDを外し、生徒氏名・講師氏名のみを表示するようにした（IDは内部処理にのみ使う）。あわせて列（生徒氏名・科目・通常担当講師・優先度・1対1）を揃えた。

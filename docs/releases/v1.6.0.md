# v1.6.0

Status: Release

## 変更内容

ユーザー要望「インストール時にデフォルトの保存先を指定しておき、workspaceを置く場所を変更
できるようにする。デフォルトの場所はあなたが指定した場所です」への対応。

既定の保存先（`%LOCALAPPDATA%\SeminarSched.WinUI`）は変更していない。設定ページから、
プロジェクトファイル・共通名簿・バックアップ・ログ等のデータ保存先（workspace）を別のフォルダー
（別ドライブや共有フォルダーなども含む）へ変更できるようにした。

「設定」ページに新しい「データの保存先」欄を追加した（アンインストール欄の上）。現在の保存先が
表示され、「保存先を変更する」ボタンから空のフォルダーを選ぶと、次回このアプリを起動したときに
データが移動する旨の確認が表示される。承認するとアプリが終了し、次回起動時に実際の移動が行われる
（実行中のアプリ自身がファイルを開いたままコピーすると壊れる恐れがあるため、あえて即座には
移動せず、何も開いていない起動直後のタイミングで行う）。移動がすべて成功してから古い場所のデータを
削除するため、途中で失敗しても元のデータは壊れたり失われたりしない。

インストーラー側に保存先選択用の新しいウィザード画面は追加していない。設定ページの機能で、
インストール直後にその場で変更すれば実質的に同じ結果になり、かつこの開発環境では対話的な
インストーラー画面を実際に確認する手段が無いため。詳細は
[ADR 0011](../adr/0011-configurable-workspace-location.md)参照。

## 検証について

- `dotnet build`成功（警告・エラー0件）。
- 既存の全テスト、合計284件がすべて通過することを確認済み（新規3件を含む）。
- 新規テストは、移動処理の中核（ネストしたファイル・フォルダーのコピー、目印ファイルの除外、
  移動元が存在しない場合に例外を投げないこと）を検証している。
- 実機での「保存先を変更する」→アプリ終了→再起動→実際の移動の確認は、この開発環境で実データを
  使った確認がしづらいため、本バージョン作成時点では行えていない（既知の制約）。

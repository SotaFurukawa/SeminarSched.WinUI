# v0.7.0 (beta)

Status: Draft Release。v0.6.1公開後、checkpoint 89（講師優先の探索調整、講師未回答バグ修正、CPU/メモリ制限の強化、集団授業への講師登録、推奨動作環境の表示）・checkpoint 90（CPU/ワーカー数の追加引き下げ、名目時間を超えても打ち切らず延長して続行）をまとめた区切り。新機能を含むため、Next Version Ruleの既定に従いv0.7.0とした。

## ハイライト

- ⑤時間割自動作成で、1対1より1対2ペアを優先、講師の空きコマを回避、1日あたりのコマ数を集約する方向へ調整した。
- アンケートに回答していない講師が「常に出勤可能」として扱われていた不具合を修正した（出席不可になる）。
- CPU使用率をさらに軽くした（Job ObjectによるOS側制限を目標35%へ、探索ワーカー数もコア数の3分の1へ引き下げ）。⑤画面の「CPU使用率を制限しない」チェックボックスで従来通り制限を外すこともできる。
- 指定した品質の名目時間内に時間割が完成しなかった場合、途中で打ち切るのではなく「少し時間を要しています」と警告を表示しつつ、最大でもう1回分の時間を使って続けて探索するようにした。
- 集団授業の受講登録画面で、担当講師も登録できるようにした。
- アプリ情報画面に推奨動作環境（CPU・メモリの目安）を表示し、お使いの環境がこれを下回る場合は警告を出すようにした。

## 主な変更点

### ⑤時間割自動作成: 講師優先の探索調整
- 1対1が多く見えるとの指摘を受け、同じ講師・同じコマに生徒2名を組み合わせられる場合はそちらを優先する加点を追加した。
- 講師の前後のコマが埋まっているのに真ん中だけ空いている「空きコマ」を避けるよう、ソフトな減点を追加した（講師の出勤不可等でどうしても避けられない場合はハードには縛らない）。
- 同じ総コマ数であれば、講師の出勤日数をできるだけ少ない日数へ集約するよう調整した（1コマのためだけに出勤させることを避ける）。
- いずれも生徒側の日程分散・間隔均等化より弱い優先度とし、生徒の都合を優先させている。

### アンケート未回答講師のバグ修正
- 候補生成のクエリが「講師単位」で出勤可否データの有無を見ていたため、アンケートに一度も回答していない講師が「常に出勤可能」として扱われ、時間割へ紛れ込んでいた。
- 判定の粒度を「プロジェクト単位」へ変更し、プロジェクト全体で出勤可否データを一度も取り込んでいない場合だけ従来通り全講師を候補に残すようにした。手動配置の競合チェックにあった別種の不具合も併せて修正した。

### CPU使用率の追加制限とチェックボックス
- Windows Job Objectでプロセス全体のCPU使用率をOS側で制限する仕組みを追加し、実機報告を受けて目標値を35%まで引き下げた。CP-SATの探索ワーカー数もコア数の3分の1まで絞るようにした。
- ⑤画面の「CPU使用率を制限しない（フルパワーで実行）」チェックボックスをオンにすると、この回だけ制限を外して実行できる。
- メモリの同様のハード制限は、超過時にクラッシュする恐れがあるため意図的に実装していない。

### 名目時間を超えても打ち切らず延長
- 指定した品質の名目時間をすべて使い切っても時間割が完成しなかった場合、これまでは打ち切ってそのまま結果を返していたが、警告を表示したうえでもう1回分の時間を使って探索を続けるようにした（最大で名目時間の2倍まで、無限には続けない）。
- 「中断して現在の結果を採用」ボタンは、この延長中も有効なまま使用できる。

### 集団授業の受講登録に講師登録を追加
- 3.2 集団授業の受講登録画面に「担当講師」欄を追加し、チェックボックスで複数の講師を登録できるようにした。
- 個別指導の自動作成・手動配置とは連携しない（情報の記録のみ）。

### アプリ情報に推奨動作環境の表示
- 10年ほど前（2015〜2016年頃）に一般的だったCPU（デスクトップ・ノートPC）を基準に、論理プロセッサ数2個以上・CPUベースクロック1.6GHz以上・メモリ4GB以上を目安として表示するようにした。
- お使いの環境がこの目安を下回る場合、アプリ情報画面に警告を表示する。

## 既知の未実装・保留

- 出力設定の表示項目ON/OFF・ロゴ画像・1ページの日数/講師列数・生徒別改ページ方式は引き続き未実装。
- 授業間隔の均等化・同一科目の連続抑制・講師優先の探索調整は、いずれもCP-SATの目的関数への近似的なソフト制約であり、常に理想的な結果を保証するものではない。
- 推奨動作環境の判定基準はコア数・クロックのみで、実際の演算性能（IPC等）は考慮していない目安に過ぎない。

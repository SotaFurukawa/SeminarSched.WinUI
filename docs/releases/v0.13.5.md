# v0.13.5 (beta)

Status: Draft Release。ユーザーからの3件の指摘への対応。bug fix/UI微調整のためpatchを上げて
v0.13.5とした。

## 対応内容

- **3.2集団授業の受講登録の「担当講師」機能を廃止し、3.1へ一元化**: checkpoint89で追加した複数人
  チェックボックス形式の担当講師登録（`GroupLessonTeacher`テーブル、自動作成・手動配置とは未連携で
  記録のみ）は、checkpoint112で導入した3.1の単一担当講師（任意・ブロッキングあり）機能と役割が
  重複し紛らわしかったため、丸ごと削除した。`GroupLessonTeacher`テーブルもDROP TABLEするマイグレー
  ションを追加した（このversionはまだ公開前のbeta版で実データが存在しないため削除して問題ない）。
  3.2画面には、担当講師の割り当ては3.1で行う旨の案内文を追加した。
- **新規プロジェクト作成フォームの年度欄**: `DatePicker`（年のみ表示）の幅が140pxと狭く、
  「2026」と入力しても「20」の部分しか見えなかった不具合を修正し、200pxへ拡大した。
- **新規プロジェクト作成フォームの「一人の講師が同時に担当できる生徒数」**: 専用の「既定値から
  変更する」チェックボックスを新設し、チェックを入れない限り数値を変更できないようにした。
  チェックを外すと既定の2人へ自動的に戻す。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

# v1.5.3

Status: Release

## 変更内容

### ①「保存先を開く」でエクスプローラーが起動しない問題への対応

ユーザー報告: クライアント環境（Windows 11）で、「2 アンケート作成」の「保存先を開く」を押しても
エクスプローラーが起動しない。

既存のコードは`Process.Start(UseShellExecute: true)`（Win32の`ShellExecuteEx`経由）でフォルダーを
開いていたが、MSIXパッケージ化されたアプリのAppContainerからこのAPIを呼び出したときの挙動は、
実行環境（Windowsのバージョン・ビルド・ポリシー設定）によって不安定になりうることが疑われる。
同じアプリ内の「8 出力設定」の「保存先を開く」は、既に`Windows.System.Launcher`
（パッケージ化アプリ向けに設計されたWinRTのランチャーAPI）を使っており、こちらは正常に動作
している。

フォルダーを開く全ての箇所（「2 アンケート作成」・ホーム画面の「最近使ったプロジェクト」）を
`Windows.System.Launcher`へ統一した。あわせて、フォルダーが見つからない場合や起動に失敗した
場合にも、実際のパスを含む明確なエラーメッセージを表示するようにした（以前は何も起きていないように
見える「無反応」になり得た）。ファイルを開く箇所（共通名簿Excel関連の2箇所）も、同じ理由で
`Windows.System.Launcher`へ統一した。

この環境ではクライアントの実機（Windows 11）を再現できないため、修正後に実際に解消するかは
ユーザー・クライアント側での確認が必要。

### ②保存先フォルダーを開くボタンの追加

ユーザー要望「保存先を開けてもいいものがいくつかある。基本情報の保存先excelなど」への対応。
ホーム画面に以下の3つのボタンを追加した。

- 「生徒講師基本情報・通常授業担当情報」カード: 「保存先フォルダーを開く」（共通名簿Excelの
  保存先フォルダー）
- 「現在のプロジェクト」カード: 「フォルダーを開く」（現在開いているプロジェクトファイルの
  保存先フォルダー）
- 同カード: 「バックアップフォルダーを開く」（プロジェクトのバックアップ保存先フォルダー）

## 検証について

- `dotnet build`成功（警告・エラー0件）。
- 既存の全テスト、合計278件がすべて通過することを確認済み。

  いない（既知の制約）。

# v0.27.2 (beta)

Status: Draft Release。受講希望一覧の表示崩れと、出力中インジケーターの配置を修正するpatch。

## 変更内容

- **受講希望一覧で、生徒氏名に学年が連結されて表示されていた問題を修正した**: 「飯島 あいみ　高3」
  のように全角スペースで氏名と学年をつなげて1列に表示していたのをやめ、学年を専用の列として
  生徒氏名の右に独立させた。
- **受講希望一覧の「隙間が大きい・列がずれて見える」という指摘を調査し、原因を特定して修正した**:
  見出し行とデータ行の列定義・列幅は完全に一致しており、ズレは発生していなかった。実際の原因は、
  数字や短い語句の列（必要回数・優先度・1対1・最大連続コマ数・空きコマ許可・学年）が見出しの
  折り返し防止のため広めの固定幅を持つ一方、値が既定の左寄せのまま描画され、列の左端に値、
  右側に大きな余白ができて隣の列と地続きに見えていたこと。該当列を見出し・データとも中央寄せに
  変更し、値が列の中央（見出しの真下）に来るようにした。氏名系の列（生徒氏名・科目名・通常担当
  講師・第1〜3希望）は従来通り左寄せのまま維持する。
- **「6 出力」ページで、出力中に表示される回転インジケーターの位置を修正した**: 従来は「Excel・
  PDFを出力」ボタンの下に独立した行として表示されていたが、ボタンの右に並べて表示するように
  変更し、インジケーターの右に「出力中」という文言も追加した。

## 検証について

既存の全テスト（計252件）がすべて通過することを確認済み。加えて実機（dev-run）で、①受講希望
一覧の生徒氏名・学年が別列で表示されること、②必要回数・優先度・1対1・最大連続コマ数・空きコマ
許可の各列で値が見出しの真下（列の中央）に表示されること、③出力ボタンを押すと、ボタンの右に
回転インジケーターと「出力中」の文言が並んで表示され、完了後は両方とも消えて生成ファイル一覧が
表示されることを確認した。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

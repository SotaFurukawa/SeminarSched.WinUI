# v0.30.0 (beta)

Status: Draft Release。集団授業と個別指導の間の空き時間の最小値（新機能）と、
UI・文言の修正11件を含むminor。

## 変更内容

- **集団授業クラスに「集団授業と個別指導の間の空き時間の最小値（分）」を追加した**: 担当講師を
  割り当てている場合、正の値を設定すると開講時間の前後にその分の空きが無い個別指導は配置できなく
  なる。マイナスの値を設定すると、その分までの重なりを許容できる（個別指導の開始・終了時刻を数分
  ずらせば集団授業に参加できる、という運用を想定）。マイナス設定で重なりを許容したまま配置された
  個別指導は、全体時間割・講師配布のExcel/PDF出力で黄色の警告として塗りつぶす。
- **時間割編集の「日別グリッド編集」の見出しと説明文を削除し、その内容をページ冒頭の説明文へ統合した**。
- **ホームの「最近使ったプロジェクト」を5件までに制限した**（従来は10件）。
- **ホームのカードの並び順を、基本情報・現在・最近・新規から、基本情報・新規・現在・最近へ変更した**。
- **「CPU使用率を制限しない」の説明文を変更した**。
- **「既に配置済みの授業は動かさない」のラベル内の「作成」を「配置」に変更し、説明文も変更した**。
- **「この回だけ探索の方針を変更する」を削除し、設定で決まった内容を読み取り専用で表示するように
  変更した**: 設定と競合する場合があるため、自動作成の実行ごとに方針を一時的に変える機能は廃止し、
  「1 プロジェクト設定」の「スケジュール設定」タブで決めた内容がそのまま使われる。説明文に「設定で
  変更できる」旨を明記した。
- **3.1集団授業クラスの説明文を変更した**。
- **3.1集団授業クラスで、「他学年の受講を許可」と「担当講師を割り当てる（任意）」を同じ行に並べ、
  前者を左側へ配置した**。また「開講日程の追加」の横幅を広げた。
- **3.2集団授業の受講登録の説明文を変更した**。
- **設定の「ライセンス」「アップデート」で、ボタンの左端・右端が揃うようにした**。

## 検証について

新規テスト5件（空き時間の最小値の保存、負の設定・正の設定それぞれでの配置可否の変化、Excel/PDF
出力の警告セル判定、最近使ったプロジェクトの件数制限）を含む既存の全テスト（計260件）がすべて
通過することを確認済み。

UIの見た目・新機能の表示については、ビルド成功とコードレベルの確認のみ行い、実機（dev-run）での
画面確認はこのバージョンでは行っていない。**次回パソコンを使用する際に、以下を目視確認していただきたい:**

1. 「3.1 集団授業クラス」で担当講師を割り当てると、「集団授業と個別指導の間の空き時間の最小値」
   欄が表示され、マイナスの値も入力できること。
2. 「4 時間割編集」「3.1 集団授業クラス」「3.2 集団授業の受講登録」の説明文が変更されていること。
3. 「ホーム」のカード順とリスト件数（最近使ったプロジェクトが5件まで）。
4. 「5 時間割自動作成」で「この回だけ探索の方針を変更する」が読み取り専用の表示に変わっていること。
5. 「設定」でライセンス・アップデートの2つのボタンの左右端が揃っていること。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

# v0.2.0 (beta)

Status: Draft Release。v0.1.0以降、ユーザーの実運用データ（共通名簿Excel・Googleフォーム実回答CSV・実プロジェクト）による検証を通じて見つかった重大バグの修正と、④時間割編集・⑤時間割自動作成・⑥出力を中心とした新機能追加を行った区切り。

## ハイライト

- 実際のGoogleフォーム回答CSV/XLSXを直接検証・反映する③アンケート取込み（生回答インポート）を新規実装し、実データでのフルパイプライン（取込み→反映→自動作成）検証で458件配置・未配置0件を確認した。
- ④時間割編集のアーキテクチャをPython版の実仕様に合わせて全面的に見直し、「事前確定」を独立機能から通常の手動配置＋ロックへ統合。ドラッグ移動・手動配置の両方にPython版と同じgreen/yellow/red判定（ハード制約違反は拒否、ソフト指標の悪化は確認ダイアログ）を実装した。
- ⑤時間割自動作成に複数探索戦略・進捗ゲージ／残り時間予測・タスクバー連携・画面外実行継続を追加。CP-SATモデルの重大なバグ（通常担当講師の最低回数がハード制約すぎてInfeasibleになる問題）を修正した。
- ⑥出力の帳票をPython版が実際に生成するxlsxと直接突き合わせ、シート構成・レイアウト・書式の相違を修正した。
- 共通名簿Excel（生徒・講師_基本情報.xlsx）の取込みとホーム画面での独立管理、Googleフォーム作成キットのApps Scriptテンプレートを実際のPython生成物と一致させる全面書き直しを行った。
- アプリ全体を日本語表示に固定し、アプリアイコンをPython版と統一した。

## ①〜⑥ 業務flow別の主な変更

### ホーム・共通基盤
- 共通名簿（生徒・講師_基本情報.xlsx）を`%LocalAppData%\SeminarSched.WinUI\Workspace\SharedRoster`で一元管理する仕組みを新設し、ホーム画面最上部から編集・新規作成・反映（開いているプロジェクトへも自動反映）ができるようにした。新規プロジェクト作成時は共通正本の内容を自動コピーする。
- ホーム画面の年度入力バグ（初回だけ既定値が入らない）を修正し、年のみを選べるドラムロール式`DatePicker`へ置き換えた。
- アプリ全体の言語設定に関わらず、日本語UIを強制表示するようにした。
- アプリアイコンをPython版のアイコン一式（1024x1024マスターから再生成）に統一した。
- プロジェクトを開いていない状態で④⑤を操作すると`NullReferenceException`で落ちるガード漏れを修正（他画面と同じ`WorkflowPageBase`パターンへ統一）。

### ①設定
- 共通名簿Excel（生徒・講師_基本情報.xlsx、通常授業シート形式）の検証・取込みに対応。
- 開校日・コマ設定をPython版と同じ月表示カレンダーに置き換え、日付ごとに使用コマを個別に切り替え可能にした。
- 生徒一覧・受講希望一覧の列ずれ（単一文字列連結表示）を、ヘッダー付きの固定幅グリッド表示へ修正。
- 講師対応科目を講師×科目のマトリクス表（校種でグループ化、セルクリックでON/OFF）へ刷新。
- コマ設定に削除ボタンを追加し、新規プロジェクトの既定コマをZ/A/B/C 4枠からA/B/C 3枠へ変更。
- 受講希望の登録・編集を①から③アンケート取込みページへ移設し、生徒ID/科目コードではなく氏名/科目名で表示するようにした。

### ②アンケート作成
- Googleフォーム作成キット（Apps Script）を、実際のPython生成済みフォームと列構成が一致するテンプレートへ全面的に書き直した（学年別ページ分岐・教科ごとの学校区分／受講回数・受講不可日時のチェックボックスグリッドを含む）。
- 生徒用・講師用フォームの回答締切を独立して設定できるようにし、保存後に保存先フォルダを直接開けるボタンを追加した。

### ③アンケート取込み
- Googleフォームの生回答CSV/XLSX（質問文そのままの列名）を直接検証・反映する取込み機能を新規実装。学校区分・受講教科・受講回数の列組合せ判定、日付・コマの抽出、未登録生徒のエラー化／体験生の自動登録、配置済み時間割がある場合のハードブロックまでPython版のロジックを移植した。
- アプリ全体がクラッシュする重大バグ（`ImportPage`のRadioButton初期化順序に起因）を修正。
- 「Googleフォーム生回答」と「旧形式（簡易CSV）」の混同を防ぐため、ファイル選択ボタンを生徒／講師で分離しレイアウトを刷新。最終的に旧形式は画面から削除した。

### ④時間割編集
- 「事前確定」を独立機能から廃止し、通常の手動配置（ロック付き）へ統合。専用ページを廃止し、④時間割編集画面へ日別グリッド編集・手動配置・変更履歴を統合した（Python版の実際の画面構成に合わせた設計変更）。
- ドラッグ移動・手動配置の両方に、Python版と同じgreen/yellow/red判定を実装。ハード制約違反（ロック済み・生徒重複など）は即拒否、ソフト指標の悪化（資格外講師・出勤可否未達・講師上限超過・優先講師との不一致など）は警告文＋はい/いいえの確認ダイアログ（理由入力可）を経てから適用する。
- 未配置カードから①生徒IDを非表示、②氏名・学年・科目略称・残り回数のみを表示、③選択中の日付に実際に配置できるものだけを一覧表示、④その日に配置可能な具体的なコマ一覧を添えるよう全面的に書き直した。出勤可否データが未設定の講師が全日程に紛れ込むバグも修正。
- 配置一覧・自動作成の差分カードに残っていた生徒ID表示も除去し、日付連動・氏名（学年）表示・回数表示を追加。
- 「すべてリセット」（ロック済み・手動配置を含む全配置の削除）を追加。
- 自動作成の差分表示（新規配置・日時変更・講師変更・未配置化の件数とカード単位の詳細）を追加。

### ⑤時間割自動作成
- 複数の探索戦略（乱数シード・ポートフォリオ探索・近傍再探索など）を品質設定に応じて順に実行し、最も良い結果を採用するようにした。進捗ゲージ・パーセンテージ・残り時間予測・現在の処理内容の表示、実行中の中断＋現在の最良結果採用に対応。
- 画面を離れても実行が継続するようにし、タスクバーへの進捗表示・完了時のオレンジバッジ通知を追加。
- CP-SATモデルの重大バグを修正：通常担当講師の最低実施回数がハード制約すぎて、生徒間の需要衝突時にモデル全体がInfeasibleになる問題を、ソフト制約＋ペナルティ方式へ変更。実データでの検証で458件配置・未配置0件の成功を確認した。
- 品質スライダーの見た目・目盛りを複数回にわたり調整。

### ⑥出力
- 帳票をPython版が実際に生成する5種の独立ファイル（全体時間割・生徒配布・講師配布〈学年順〉・講師配布〈講師別〉・未配置一覧）構成へ再編成。
- Python版が実際に生成したxlsxと直接突き合わせ、シート構成・列見出し・結合範囲・配色などの相違を修正した。

## 既知の未実装・保留

- 未配置一覧以外（配置一覧・自動作成の差分カード）への配置可能コマのヒント表示は未対応。
- ドラッグ移動・手動配置のソフト指標プレビューは、優先講師一致度等のスコアリングベースの指標（移動のみ対応）と、資格・出勤可否・講師上限（移動・追加とも対応）に限定。`unassigned_count`/`changed_existing_assignment_count`など全体差分ベースの指標は未移植。
- ドラッグ中のセルのリアルタイム色分けは未実装（ドロップ確定後の確認ダイアログのみ）。
- Google Forms作成キットの実際のGoogle上での動作確認は未実施（この開発環境からはGoogleへ到達できないため）。
- 3ペインレイアウト・学年や科目によるフィルタ・ズームスライダーは見送り（機能面のギャップではなくレイアウトの好みの差と判断）。
- 最適化の残りの辞書式目的（生徒週偏り・担当講師分散・講師稼働率公平性など）の完全実装は継続課題。

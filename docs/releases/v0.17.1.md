# v0.17.1 (beta)

Status: Draft Release。UI微調整のためpatchを上げてv0.17.1とした。

## 対応内容

- **①設定画面の各タブの横幅が狭い**: ページ全体の横幅がMaxWidth="960"で固定されており、
  ウィンドウを広げても表（特に「講師指導可能科目」の○×マトリクス）が狭いままだった。この
  固定幅を撤廃し、ページがウィンドウの横幅いっぱいまで使えるようにした。「コマ・開校日」タブの
  コマ設定表のように、元々列数が少なく横幅を必要としない表は、従来どおり自然なサイズのまま
  右側に余白ができる（これは意図した見た目）。
- **「講師指導可能科目」マトリクスの枠線が薄すぎる**: 表の各セル（見出し・講師ID/氏名・○の
  切り替えボタン）に明示的な境界線が設定されておらず、セル間の隙間だけで格子状に見えていたため
  非常に薄かった。全セルへ共通の、少し濃いグレーの枠線を明示的に設定した。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

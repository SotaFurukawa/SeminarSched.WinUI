# v0.13.2 (beta)

Status: Draft Release。ユーザー報告「0.13.1をGitHubからインストールしようとしたら失敗し、
エラーコード1が出る」の調査で見つかった不具合の修正。bug fixのためpatchを上げてv0.13.2とした。

## 修正内容

- `Package.appxmanifest`のIdentity/Versionが単なる静的なXML属性で、ビルド時に
  `Directory.Build.props`のバージョンから自動反映されていなかったため、v0.9.1からv0.13.1までの
  すべてのDraft Releaseの`.msix`が、ファイル名やアプリ内の表示は正しいバージョンなのに、Windowsの
  パッケージマネージャーが実際に識別するIdentity Versionは一貫して`0.9.0.0`のまま出荷され続けて
  いた。`scripts\New-MsixPackage.ps1`でビルド前に`Package.appxmanifest`を同期するよう修正し、
  以降このズレが起きても検知できるよう回帰テストを追加した。
- ユーザーが実際に遭遇した「エラーコード1」自体は、開発機で`dotnet run`を多数回実行していたことで
  Windowsに残っていた「パッケージ化されていない開発モードのアプリ」登録が原因で、開発機だけの事象
  だったことを確認した（エンドユーザー環境では発生しない）。この登録は削除して解消したが、上記の
  Identity Version不一致という別の潜在バグをあわせて修正した。

詳細は[ADR 0005](../adr/0005-windows-distribution.md)のAmendmentを参照。

このversionのGitHub ReleaseはDraftとして作成する。

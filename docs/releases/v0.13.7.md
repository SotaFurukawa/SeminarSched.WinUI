# v0.13.7 (beta)

Status: Draft Release。v0.13.6のアイコン・表示名変更を実際に確認したユーザーからの4件の指摘への
対応。すべてUI微調整のためpatchを上げてv0.13.7とした。

## 対応内容

- **アプリアイコンをさらに拡大**: v0.13.6の新アイコンは、実際の描画内容（isometricな台座＋
  ブロック）の周囲に上下左右非対称の余白が残っており、特に上下方向の余白が大きく「小さく見える」
  原因になっていた。SVGのviewBoxを実際の描画内容の外接矩形に合わせて絞り込み、正方形フレーム
  いっぱいに大きく見えるよう全アセットを再生成した。
- **⑤時間割自動作成中インジケーターの表示切替**: ナビゲーションペインを縦長にして左タブが
  アイコンのみ（Compact/Minimal）になったときに使う円形ゲージ（checkpoint115）が、Compact幅
  からはみ出して表示が欠けていた不具合を修正した。円のサイズを56x56から28x28へ縮小し、既定の
  Compactペイン幅（48px）に収まるようにした。また、このゲージは本来「ペインがアイコンのみに
  なったとき専用」の簡易表示だったため、通常の展開時（ラベルが見えている状態）はcheckpoint115
  より前の仕様（タイトル・進捗バー・パーセンテージ＋残り時間のテキスト）に戻し、
  `NavigationView.DisplayMode`に応じて自動的に切り替えるようにした。
- **新規プロジェクト作成フォームの年度欄の空白**: `DatePicker`の`DayVisible`/`MonthVisible`を
  `False`にしても、非表示にした日・月の列幅がWinUIの内部実装で回収されず、年の値が右寄りに
  表示され左側に不要な空白ができる不具合があった。年度欄を`NumberBox`へ置き換え、空白なく
  左詰めで表示されるようにした。
- **設定画面のタブ見出しの折り返し**: `TabView`の見出し文字列が長いタブ（「講師指導可能科目」
  「通常授業担当設定」「コマ・開校日」「スケジュール設定」等）で文字が途中で隠れていた不具合を
  修正した。各タブの見出しを2行まで折り返し表示できるようにし、タブの高さも合わせて拡張した。
  この対応で見出しを文字列指定からXAML要素指定に変更したため、UI Automationの名前が失われる
  副作用が生じていたが、`AutomationProperties.Name`を明示指定して回避した。
  同じ画面の「一人の講師が同時に担当できる生徒数（既定は2人）」は逆に折り返されないよう、
  入力欄の幅を260pxから420pxへ拡大した。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

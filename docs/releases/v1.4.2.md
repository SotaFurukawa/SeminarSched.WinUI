# v1.4.2

Status: Release

## 変更内容

v1.4.0で追加した「中学受験と中学受験以外を分ける」オプションについて、置き場所をホーム画面の
プロジェクト作成時設定へ移す変更（v1.4.1としてcommit・push済み、GitHub Releaseは未公開）を
行ったが、ユーザーから直後に「あ！やっぱりやめます！元のままでいいです！」と取り消しの指示が
あった。確認の結果、配置の変更だけを取り消し、「中学受験と中学受験以外を分ける」機能自体は
維持する、という意図だった。

該当commitを`git revert`で取り消し、v1.4.0の設計（「2 アンケート作成」ページのその場限りの
チェックボックス）へ戻した。コード・挙動はv1.4.0と完全に同一。公開済みのversionを使い回さない
方針のため、取り消し後の状態を新しいversion（v1.4.2）として改めてリリースした。

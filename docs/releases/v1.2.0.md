# v1.2.0

Status: Release（生徒・講師・講師指導可能科目・通常授業担当設定・科目の管理を、プロジェクトごと
ではなく一括管理にした新機能）。

## 変更内容

- **新しい左ナビ「0 基本情報設定」を追加した。** プロジェクトを開いていなくても使える画面で、
  生徒・講師・講師指導可能科目・通常授業担当設定・科目を直接編集できる。これまではプロジェクトの
  「1 プロジェクト設定」内でしか編集できなかったが、今回これらのタブはそちらから外し、
  「0 基本情報設定」へ一本化した（「1 プロジェクト設定」には、そのプロジェクト固有の
  コマ・開校日・スケジュール設定・出力設定だけが残る）。
- **「0 基本情報設定」で保存・削除すると、共通名簿Excel（生徒・講師_基本情報.xlsx）へ即座に
  反映されるようにした。** これまでは共通名簿Excelの内容をプロジェクトへ取り込む一方向しか
  無かったが、今回「0 基本情報設定」での変更がすぐにExcel側へも書き戻されるようになった
  （Excelを開いたまま保存しようとした場合は、保存自体は成功したうえで「Excelを閉じてから
  保存し直してください」という案内を表示する）。
- 既存のプロジェクトは引き続き自分自身の生徒・講師等のデータ（その時点のスナップショット）を
  持ち、時間割自動作成はそこから読む。最新の基本情報をプロジェクトへ反映したい場合は、従来どおり
  ホーム画面の「共通名簿を取込む」を使う。

## 検証について

既存の全テスト（計267件、うち新規1件）がすべて通過することを確認済み。新規テストは、共通正本DB
を直接編集した変更が、無条件再生成（RefreshWorkbookAsync）でのみ共通名簿Excelへ反映されることを
検証している。「0 基本情報設定」画面そのもの（ナビゲーション・タブ切替・保存後のExcel即時反映）
の実機UI確認は、この開発環境のスクリーンショット手段に問題があり、本バージョン作成時点ではまだ
行えていない。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)および
[docs/adr/0008-centralized-basic-info.md](../adr/0008-centralized-basic-info.md)を参照。

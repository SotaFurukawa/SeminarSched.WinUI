# v0.13.0 (beta)

Status: Draft Release。checkpoint110で提示され、v0.12.0では見送っていた「集団授業のクラスに任意で
担当講師を割り当てる」機能を実装した。新機能のためminorを上げてv0.13.0とした。

## ハイライト

- 3.1集団授業クラスのクラス登録フォームに「担当講師を割り当てる（任意）」チェックボックスを追加した。
  チェックすると講師を1名選べるようになり、割り当てるとその講師はこのクラスの開講日程（複数可）の
  時間帯に個別授業を配置できなくなる（自動作成の候補からも除外され、④時間割編集でもその時間帯は
  出勤不可として扱われる）。割り当てようとした時間に既にその講師の個別指導配置がある場合は、保存を
  中止しエラーメッセージで知らせる。
- ⑥出力の全体時間割（Excel・PDF）で、担当講師を割り当てたクラスの開講時間と重なるコマを黒塗り
  「集団」表示にした（生徒配布ページの集団授業表示と同じ意匠）。

## 対象外・既知の制約

- 集団授業の受講登録画面（3.2）に以前からある「担当講師」の複数人チェックボックス一覧は、今回も
  記録のみの独立した機能のまま（自動作成・手動配置とは連携しない）。今回追加したのは3.1クラス登録
  フォームの単一の任意担当講師で、両者は別のデータとして管理される。
- 担当講師のその日の全体像を確認できるのは全体時間割のみで、講師配布時間割（個人ごとのxlsx）には
  今回反映していない。

## 動作確認・副次的に発見した既存バグ

- サブエージェントによる実機相当の起動確認で、担当講師割り当て→ブロック→自動作成での除外→
  全体時間割への「集団」表示まで一連の流れを確認した。
- 今回の変更とは無関係の既存バグを発見: 配置が1件も無い状態（自動作成前）で⑥出力の生徒配布・
  講師配布PDFを生成すると、ページが1枚も無いままPDF保存を試みてアプリごとクラッシュする
  （`PdfScheduleReportRenderer`）。原子的な出力設計のため部分ファイルは残らないが、次のversionで
  対応を検討する。

詳細は[機能同等性台帳](../FEATURE_PARITY.md)を参照。

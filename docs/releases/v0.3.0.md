# v0.3.0 (beta)

Status: Draft Release。v0.2.0以降、ユーザーの実運用フィードバックに基づく新機能追加（Googleフォーム作成手順の画像付きガイド、集団授業クラス・受講登録の新機能）と、実機ログから見つかった不具合修正（⑥出力のクラッシュ、プロジェクト新規作成の同名衝突）を行った区切り。

## ハイライト

- ②アンケート作成に、Python版が持っていた画像13枚の「Googleフォーム作成手順」ガイドをポップアップ（別ウィンドウ表示も可能）として移植した。
- 個別指導以外に受講する集団授業（クラスと開講日程・受講生）を登録できる新機能を追加した。左ナビゲーションに専用ページ「3.1 集団授業クラス」「3.2 集団授業の受講登録」を新設し、3.1はカレンダーへチェックを入れてクラス・時刻帯を一括登録する方式にした。
- 新規プロジェクト作成で同名ファイルが既に存在する場合、エラーで止めるのではなく「(2)」を付けて自動的に保存し、警告で知らせるようにした。
- ⑥出力で、出勤不可情報はあるが最終的に配置が1件も無かった講師がいると`KeyNotFoundException`でクラッシュする不具合を修正した（実機ログから発見）。
- 最近使ったプロジェクトの一覧に「フォルダーを開く」ボタンと最終更新日を追加し、講習区分に「その他」（名称を自由入力）を追加した。
- ⑤品質スライダーの目盛り数字の位置を、WinUIのテーマリソースから実測した正しい値で揃えた。

## 主な変更点

### ②アンケート作成
- 「作成手順」ボタンから、Python版と同じ10手順・画像13枚の作成手順ガイドをポップアップ表示できるようにした。「別ウィンドウで表示」でモーダルを閉じて独立したウィンドウでも開ける。

### 集団授業（新機能）
- ホーム画面の新規プロジェクト作成に「集団授業の日程を考慮する」チェックボックスを追加（作成時のみ設定可）。オンにしたプロジェクトでのみ、左ナビゲーションに「3.1 集団授業クラス」「3.2 集団授業の受講登録」が現れる。
- 3.1: クラス名・対象学年・他学年受講許可を登録し、下のカレンダー（①設定のコマ・開校日カレンダーと同じ方式）で日付にチェックを入れてから、クラス・開始時刻・終了時刻を指定して「選択した日に追加」を押すと、選択した全日付へ一括登録される。同じ日に複数のクラスを追加すると、そのマスに積み重なって表示される。
- 3.2: クラスを選ぶと対象学年の生徒がチェックボックス付きで一覧表示され（「他学年の受講を許可」がオンなら全学年）、チェックの都度その場で反映される。
- Python版はこの機能をv1.6.0以降UI停止中（DB/serviceのみ残存）だが、「1回の開講＝1行」でクラス/series概念が無くクラス単位の受講登録UIも無かったため、そのまま復活はさせずユーザー指示に基づく独自設計で実装した。

### プロジェクト管理・ホーム画面
- 新規作成時、同名の`.jukuschedule`ファイルが既に存在する場合はエラーにせず「名前(2)」のように自動的に名前を変えて保存し、警告で通知する。
- 最近使ったプロジェクトの各行に「フォルダーを開く」ボタンと、ファイルの実際の最終更新日時を追加表示。
- 講習区分に「その他」を追加。選択すると名称入力欄が表示され、その名称がプロジェクト名に反映される。

### ⑤時間割自動作成
- 品質スライダーの目盛り数字（1〜5）の位置がスライダーの実際のtick位置とずれる問題を、固定pxの決め打ちではなくWinUIのテーマリソース（thumb幅）から実測した値で揃えるよう修正した。

### ⑥出力（バグ修正）
- 出勤不可情報（`TeacherUnavailability`）だけが登録され、最終的に一度も配置されなかった講師がいると、全体時間割の生成が`KeyNotFoundException`でクラッシュしていた不具合を修正（Excel・PDF両方）。実機ログでの実際のクラッシュを確認した上で対応した。

## 既知の未実装・保留

- 集団授業の受講時間帯を④時間割編集・⑤時間割自動作成の制約（個別指導との二重予約回避）へは連携していない（データの登録・カレンダー表示のみ）。
- Google Forms作成キットの実際のGoogle上での動作確認は未実施（この開発環境からはGoogleへ到達できないため）。
- v0.2.0リリースノート記載の既知の未実装・保留事項（全体差分ベースのソフト指標、ドラッグ中のライブ色分け等）は引き続き未対応。

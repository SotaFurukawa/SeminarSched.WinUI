# v0.31.0 (beta)

Status: Draft Release。集団授業と個別指導の間の空き時間の最小値を、講師側・生徒側で
別々に設定できるようにするminor。

## 変更内容

- **「集団授業と個別指導の間の空き時間の最小値」を、講師側・生徒側それぞれ別の値で設定できるように
  した**: これまでは1つの値しかなく、実際には担当講師にしか効果が無かった。今回から、このクラスへ
  受講登録した生徒全員についても同じ考え方（正の値で空き時間を要求、負の値で軽微な重なりを許容）で
  個別指導の配置をブロックできるようにした。生徒側の設定は、担当講師の割り当ての有無に関わらず常に
  効果がある。
- 生徒側のブロックは、自動作成（ソルバー）・保存前の独立検証・手動配置のプレビュー・ドラッグ中の
  禁止マーク表示・出力の未配置理由診断のすべてに反映した。

## 検証について

新規・更新テストを含む既存の全テスト（計263件）がすべて通過することを確認済み。UIの見た目・実機
での自動作成/手動配置の実際の挙動については、ビルド成功とコードレベルの確認のみ行い、実機
（dev-run）での画面確認はこのバージョンでは行っていない。**次回パソコンを使用する際に、以下を
目視確認していただきたい:**

1. 「3.1 集団授業クラス」に「生徒側」「講師側」2つの空き時間欄が表示され、どちらも負の値を
   入力できること（生徒側は担当講師の有無に関わらず常に表示される）。
2. 生徒側に負の値を設定して受講登録した生徒の個別指導を、わずかに重なるコマへ実際に配置できること。
3. 正の値を設定した場合、開講時間と離れたコマでも配置できなくなること。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

# v0.27.1 (beta)

Status: Draft Release。既存UIの表示崩れ3件を修正するpatch。

## 変更内容

- **講師指導可能科目の表の縦幅を、ウィンドウの高さに応じて動的に広げるようにした**: 従来は
  `MaxHeight="480"`で固定されており、ウィンドウを大きくしても表の下に大きな余白ができていた。
  ウィンドウの実高さから動的に計算し、ウィンドウ最下部より少し上（約24px）に表の最下部が来る
  ようにした。ウィンドウのリサイズやタブ切り替えのたびに再計算される。
- **講師指導可能科目の表で、校種（小学校・中学校・高校）の見出しが消えて見える不具合を修正した**:
  校種グループの見出しは複数列（高校は14列）にまたがる1つのセルで、中央寄せのままだと見出し
  文字がグループの中央、すなわち初期表示のスクロール位置ではビューポート外に描画されてしまい、
  実質「見出しが消えている」ように見えていた（グループ分け自体のロジックに誤りはなかった）。
  見出しを左寄せにし、グループの先頭列が見えた時点で見出しも読めるようにした。
- **ウィンドウを横に短くしてナビゲーションペインがアイコンのみ表示になったとき、時間割自動作成の
  円形ゲージが他のアイコンより左に寄って見える不具合を修正した**: 標準のメニューアイコンはペイン
  左端から内側へ一定のマージンを取った領域の中で中央寄せされるが、ゲージを置いているPaneFooter
  の領域にはそのマージンが無いため、単純な中央寄せだと標準アイコンより左に寄って見えていた。
  実機でピクセル単位の位置を検証し、マージンを調整して標準アイコンと中心が揃うようにした。

## 検証について

既存の全テスト（計252件）がすべて通過することを確認済み。加えて実機（dev-run）で、①講師指導
可能科目タブを開いた状態でウィンドウの高さを変えると表の下端がウィンドウ下端近くまで伸びる
こと、②「高校」グループの見出しが初期表示から見えること、③ウィンドウを横に狭めてペインが
アイコンのみになったとき、強制的にゲージを表示させた状態で標準アイコン（ホーム・設定等）の
中心線とゲージの中心がピクセル単位でほぼ一致すること（円のあてはめ計算で中心x座標の差0.5px
未満）を確認した。

# v1.8.0

Status: Release

## 変更内容

アンケート作成（②アンケート作成）について、ユーザー指示3点に対応した。詳細は
[ADR 0010のAmendment](../adr/0010-questionnaire-entrance-exam-question-toggle.md)参照。

### 1. 「他学年を含む」チェックボックスのタイトルを変更

「中高一貫などで他学年の授業を受講される際はこちらにチェックを入れてください」から
「私立中学の中高一貫の生徒はこちらにチェックを入れてください」へ変更した。

### 2. 「在籍区分（在籍生／体験生）」アンケートを廃止

フォームから「在籍区分（必須）」の質問を削除した。この質問は、アンケート取込み時に「基本情報に
一致しない生徒」が「在籍生」の自己申告ならエラーでimportをブロックし、「体験生」の自己申告なら
警告のうえプロジェクト内だけに自動登録する、という判定材料として使われていた。

質問自体の廃止によりこの判定材料が無くなったため、**基本情報に一致しない生徒は、理由（入力
ミスか本当の体験生か）を区別せず、一律で警告のうえ自動登録する方式へ統一した。** スタッフは
取込みのPreview画面で警告一覧を見て反映前に気付けるが、「入力ミスを早期に強制的に止める」という
以前の保護は失われる、という意図的な挙動変更であることに注意してほしい。

### 3. 「他学年を含む」ページの学校区分を科目名への付記へ統合

以前は「学校区分」のドロップダウンと「受講教科」が別々の質問だったが、これを「数学（中学範囲）」
のように1つの質問へ統合した。

v1.5.0で一度導入し、実際のデモで回答者自身の学年と科目の学校区分が矛盾する回答が発生したため
v1.5.2で差し戻した、似た付記機能とは設計が異なる。今回は**別途の「学校区分」ドロップダウン
自体を廃止**しており、尋ねる項目が1つしか無いため、同じ矛盾は構造的に起こり得ない。

内部的には、整形済み回答シートの列構成（「学校区分」「受講教科」の2列）は変更していない。
Google Apps Script側で、回答された付記付き科目名を元の科目名と学校区分へ分解してから、従来通り
2列へ書き込むようにしたため、アプリ側（`CourseSurveyImportService`）は無改修。

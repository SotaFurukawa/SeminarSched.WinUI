# v0.23.0 (beta)

Status: Draft Release。受講希望一覧の入力方式刷新・列追加という新機能のためminorを上げてv0.23.0とした。

## 変更内容

- **受講希望一覧を行内編集方式に刷新**: アンケート取込ページの「受講希望」も、生徒・講師・科目
  タブ（v0.22.0）と同じ行内編集方式に統一した。常時表示の入力フォームを廃止し、検索欄の右の
  「受講希望を追加」ボタンで一覧の最下部に新しい編集行を表示し、その場で入力して保存する。
  既存の行は、一覧の行にカーソルを合わせたときに表示される「変更」ボタンで、同じように行内で
  編集できる。
- **受講希望一覧に3項目を列として追加**: これまで編集フォームでしか確認できなかった
  「最大連続コマ数上書き」「第1〜3希望講師」「空きコマ許可上書き」を、一覧の右側に列として
  表示するようにした（未設定の場合は「既定値」「指定なし」と表示）。
- **「選択した行を削除」を行ごとの削除ボタンに変更**: 行の選択という概念がなくなったため、
  一覧の行にカーソルを合わせたときに「変更」の隣へ表示される「削除」ボタンへ変更した
  （確認ダイアログ経由、取り消し不可）。
- 列数が増えたため、ウィンドウ幅が狭い場合は見出し・一覧をまとめて横スクロールできるようにした。

## 検証について

実際のテストプロジェクトデータ（受講希望約190件を含む）を使い、実機（dev-run）で確認した：
①新しい列（最大連続コマ数上書き・第1〜3希望・空きコマ許可上書き）がすべて正しく表示される
こと、②「受講希望を追加」→一覧最下部へ自動スクロール→生徒・科目・通常担当講師等を選択→
保存→一覧へ正しく反映されること（通常担当講師を選ぶと第1希望講師へ自動補完される挙動を
含む）、③検索フィルタ、④行ホバーで「変更」「削除」ボタンが表示されること、⑤削除の確認
ダイアログと実際の削除。

既存の全テスト（計252件）がすべて通過することも確認済み。

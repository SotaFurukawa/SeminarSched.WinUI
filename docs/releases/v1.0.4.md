# v1.0.4

Status: Release（「新規で基本情報を作成」の保存直後に、Excelを自動的に開くようにしたUI微調整）。

## 変更内容

- **「新規で基本情報を作成」で保存場所を選んでテンプレートを保存すると、保存直後にそのExcelが
  既定のアプリで自動的に開くようにした**。これまでは保存するだけで、開くには保存先フォルダーから
  手動で開く必要があった。既存の「Excelで編集」ボタンと同じ挙動にそろえた。

## 検証について

既存の全テスト（計263件）がすべて通過することを確認済み。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

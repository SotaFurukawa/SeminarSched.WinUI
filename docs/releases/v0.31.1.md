# v0.31.1 (beta)

Status: Draft Release。一覧でカーソルを合わせたときに行がズレる不具合を修正するpatch。

## 変更内容

- **生徒・講師・通常授業担当設定・科目（①設定）、受講希望一覧（③アンケート取込）の一覧で、行に
  カーソルを合わせたときに行が少し上下にズレる不具合を修正した**: ホバー時だけ表示される
  「変更」「削除」ボタンが通常の文字列より背が高く、表示のたびに行の高さが伸び縮みしていたことが
  原因だった。行の高さを固定し、代わりにホバー中は行の背景を少し濃いグレーに変えることで、
  ズレの無いホバー表現にした。

## 検証について

既存の全テスト（計263件）がすべて通過することを確認済み（見た目だけの修正のため新規テストは
追加していない）。実機（dev-run）での画面確認はこのバージョンでは行っていない。**次回パソコンを
使用する際に、「1 プロジェクト設定」の生徒・講師・通常授業担当設定・科目の各タブと、「3 アンケート
取込」の受講希望一覧で、行にカーソルを合わせてもズレず、背景が少し濃いグレーになることを確認して
いただきたい。**

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

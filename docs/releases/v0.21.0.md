# v0.21.0 (beta)

Status: Draft Release。新機能を含むためminorを上げ、patchを0へリセットしてv0.21.0とした。

## 新機能

- **保存などの成功通知を、iPhoneの通知のようなスライド式トーストへ変更**: 以前は各ページの
  決まった位置にInfoBarとして表示され、表示のたびにページが一番上まで自動スクロールされて
  しまっていた（複数件を続けて操作するときに毎回スクロールし直す必要があり煩わしいという
  指摘があった）。保存・削除など単発の操作結果を知らせるだけの通知は、ページのスクロール
  位置に影響しない固定オーバーレイへ変更し、ウィンドウ上部からスライドインするようにした。
  2件目の通知が来た場合は、表示中の通知を先にスライドアウトさせてから2件目をスライドイン
  させる。右側の×ボタンでいつでも閉じられる（約4秒で自動的にも閉じる）。なお、検証結果や
  出力結果の件数など「読んでおくべき内容を含む」通知は、従来どおりページ内に表示したままに
  している。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

## 検証について

一時的な別パッケージIDの実機ビルドで、①通知表示時にページのスクロール位置が変わらないこと、
②ウィンドウ上部からスライドインすること、③2件目の通知が来たときに1件目をスライドアウト
させてから2件目がスライドインすること、④×ボタンで閉じられること、⑤警告・エラー系の通知が
従来どおりページ内に表示されたままであること、をスクリーンショットで確認してから出荷した。
検証用のテストパッケージ登録は確認後に削除済み。

このversionのGitHub ReleaseはDraftとして作成する。

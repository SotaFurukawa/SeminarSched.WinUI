# v1.6.1

Status: Release

## 変更内容

ユーザー報告「アンケート作成後に開こうとしても開けなかった」への対応。

`WorkspacePaths.Output`/`Forms`（Workspace配下の各フォルダ）は、以前はその機能を初めて使ったとき
（出力ページ・アンケート作成ページの「作成」「出力」を初めて押したとき）に遅延して作られる仕様
だった。使う前にフォルダを探すとまだ存在しない状態になり得、「保存先が無い」という見え方に
つながっていた。

インストーラー（Inno Setup）に`[Dirs]`セクションを追加し、Workspace配下の各フォルダ
（Projects/Backups/Output/Forms/SharedRoster）とlogsフォルダを、インストール時にあらかじめ
作っておくようにした。`uninsneveruninstall`フラグを付け、アンインストール時にはこれらのフォルダを
削除しないようにしている（既存の「ユーザーデータはアンインストールしても消さない」方針を維持）。

なお、アンケート作成キットや出力一式自体は、この中に都度新しいタイムスタンプ付きサブフォルダを
作って保存する仕組み自体は変更していない。この生成ごとのサブフォルダが、生成に成功した直後には
確実に存在する（アプリ自身がこれを削除する処理は無い）ため、もし生成後に無くなっていた場合は、
外部（ユーザー自身の後片付け・ウイルス対策ソフト等）による削除が原因と考えられる。

## 検証について

- `dotnet build`成功（警告・エラー0件）。
- 既存の全テスト、合計284件がすべて通過することを確認済み（コード側の変更は無く、インストーラー

  確認は、この開発環境でインストール状態を都度再現する必要があるため、本バージョン作成時点では
  行えていない（既知の制約）。

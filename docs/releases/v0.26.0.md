# v0.26.0 (beta)

Status: Draft Release。通常授業担当設定・コマ設定の行内編集化という新機能のためminorを上げて
v0.26.0とした。

## 変更内容

- **通常授業担当設定タブを行内編集方式に刷新した**: 常時表示の入力フォームを廃止し、生徒・講師・
  科目タブ（v0.22.0）や受講希望一覧（v0.23.0）と同じ「追加」ボタン＋行ホバーの「変更」ボタンで、
  一覧の行内でそのまま編集する方式に統一した。削除機能は生徒・講師タブ同様に設けていない。
  保存は生徒・科目の組をキーにしたUPSERTのため、既存行の編集中は生徒・科目を変更できないように
  した（変更したい場合は追加し直す）。
- **コマ設定タブ（コマ・開校日タブの上半分）も同様に行内編集方式へ刷新した**: 常時表示の入力
  フォーム＋一覧クリックでの読み込みをやめ、「コマを追加」ボタン＋行の「変更」ボタンで編集する
  方式にした。ただし▲▼（並び替え）・×（削除）ボタンは元々このタブで常時表示だったため、他タブの
  ホバー表示方式には合わせず、新設の「変更」ボタンも含めて常時表示のまま維持している。

## 検証について

既存の全テスト（計252件）がすべて通過することを確認済み（出力生成系テストで並列実行時に時々
発生する一時ディレクトリの競合によるものとみられる無関係なflakeを、並列実行を無効化して再現性
を確認したうえで切り分け済み）。加えて実機（dev-run）で、①通常授業担当設定タブが新しい行内
編集UI（追加ボタン・検索欄・行ホバーの変更ボタン）で正しく表示されること、②コマ設定タブで
既存コマの「変更」ボタンから編集行が開き、コード・表示名・時刻・有効状態が正しく読み込まれる
こと、③保存→一覧へ反映されることを確認した。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

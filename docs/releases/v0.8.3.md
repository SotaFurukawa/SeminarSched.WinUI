# v0.8.3 (beta)

Status: Draft Release。ユーザー指示「優先度5について、これは必須です。通常授業講師と第一から第三
希望講師以外からは絶対に選ばないようにしてください」への対応（checkpoint 102）。bug fixのため
Next Version Ruleの既定に従いv0.8.3とした。

## ハイライト

- 担当講師優先度5（固定）の受講希望は、通常担当講師・第1〜3希望講師の最大4名に候補を**無条件で**
  限定するようにした。従来は、この4名の空きコマだけでは必要回数を満たせない場合に限り、絞り込み
  自体を適用せず他の講師も候補に戻す救済処理があったが、ユーザーの明示的な指示によりこれを廃止
  した。満たせない分は、他の講師を使うのではなく未配置のまま残す。

## 主な変更点

- `SqliteScheduleRunService.RestrictPriorityFiveCandidatesToPreferredTeachers`から、通常担当講師の
  出勤可能コマ数が必要回数に満たない場合に絞り込みを解除する分岐を削除した。優先度5かつ通常担当
  講師が設定されている受講希望は、常に「通常担当講師＋第1希望＋第2希望＋第3希望」の候補のみに
  限定される。
- 未配置が発生した場合の診断（⑤画面の警告メッセージ）も、この変更に合わせて文言を更新した。
  あわせて、checkpoint100でタブ名を変更した際に更新し忘れていた案内文（「①設定の担当設定タブ」）
  を、現在の正しいタブ名（「通常授業担当設定」「講師指導可能科目」）へ修正した。

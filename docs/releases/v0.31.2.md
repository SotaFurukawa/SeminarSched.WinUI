# v0.31.2 (beta)

Status: Draft Release。行内編集に「取消」ボタンを追加するpatch。

## 変更内容

- **一覧の行内編集（生徒・講師・通常授業担当設定・科目、受講希望一覧）に「取消」ボタンを追加した**:
  これまでは「保存」しか無く、編集を途中でやめる手段が無かった。「保存」の右側に「取消」を追加し、
  押すと変更を保存せずに編集を終了する（新規追加の行を取消した場合はその行自体が無くなる）。

## 検証について

既存の全テスト（計263件）がすべて通過することを確認済み（見た目だけの変更のため新規テストは
追加していない）。実機（dev-run）での画面確認はこのバージョンでは行っていない。**次回パソコンを
使用する際に、「1 プロジェクト設定」の生徒・講師・通常授業担当設定・科目の各タブと、「3 アンケート
取込」の受講希望一覧で、行の編集中に「取消」を押すと変更が保存されず編集が終わることを確認して
いただきたい。**

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

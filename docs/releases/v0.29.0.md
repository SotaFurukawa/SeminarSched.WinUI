# v0.29.0 (beta)

Status: Draft Release。日別グリッド編集の矢印ボタン位置調整と、自動作成の入れ替え提案機能を追加するminor。

## 変更内容

- **日別グリッド編集の日付左右の前後矢印ボタンを、日付の枠の真横（隙間なし）に配置し、縦幅を揃えて
  上下端が同じ高さになるようにした**: ボタンと日付欄が1つの区切りの無い帯に見えるようにした。
- **時間割自動作成で「既に配置済みの授業は動かさない」設定を使った結果、未配置が残ったとき、
  既存の配置を1件だけ別のコマへ動かせば配置できる組み合わせがあれば警告を出すようにした**: 候補
  ごとに「入れ替えて配置する」「配置せずそのままにする」の2つのボタンを表示する。入れ替えは
  できるだけ最小になるよう、1件の移動だけで解決できる組み合わせのみを提案する（連鎖的な入れ替えは
  行わない）。ロック済み・手動配置済みのコマは動かさない。

## 検証について

既存の全テスト（計252件）に加え、入れ替え提案機能の新規テスト3件（入れ替え候補が正しく見つかり
適用できること、占有している配置が動かせない場合は提案されないこと、移動先が存在しない場合は
提案されないこと）を追加し、計255件がすべて通過することを確認済み。

矢印ボタンの見た目、および入れ替え提案のUI（カード表示・ボタンの動作）については、ビルド成功と
コードレベルの確認（ロジックの手作業トレース、新規テストの通過）のみ行い、実機（dev-run）での
画面確認はこのバージョンでは行っていない。検証を試みた時点でユーザーが別の作業でパソコンを
使用中だったため、誤操作のリスクを避けて自動クリックによる実機確認を見送った。**次回パソコンを
使用する際に、以下を目視確認していただきたい:**

1. 「4 時間割編集」で、日付左右の矢印ボタンが日付の枠にぴったり隣接し、上下端が揃って見えること。
2. 「5 時間割自動作成」で「既に配置済みの授業は動かさない」をオンにして未配置が残る状況を作り、
   入れ替え候補が表示されたら「入れ替えて配置する」を押して正しく配置されること、「配置せずその
   ままにする」を押すとその候補だけが一覧から消えること。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

# v1.0.1

Status: Release（v1.0.0の公開直後に判明したインストーラー不具合の修正）。

## 変更内容

- **別のパソコンにインストールしようとすると失敗する不具合を修正した**: v1.0.0のインストーラー
  （`SeminarSched.WinUI-Setup-1.0.0.exe`）は、証明書の信頼登録を現在のユーザーの範囲だけに
  行っていたため、この証明書を一度も信頼したことがないパソコンでは
  「証明書チェーンは処理されましたが、信頼プロバイダーが信頼していないルート証明書で強制終了
  しました」というエラーでインストールに失敗していた。証明書をパソコン全体の信頼ストアへ登録する
  よう変更し、この問題を解消した。
- **この変更に伴い、インストール時にUAC（ユーザーアカウント制御）の確認画面が表示されるように
  なった**: 「はい」を選んで進めてください。これまでの「管理者権限不要」という手軽さは、確実に
  インストールできることを優先してトレードオフとした。

## 検証について

既存の全テスト（計263件）がすべて通過することを確認済み。インストーラーの修正自体については、
実際に問題が発生した別のパソコンでの再試行による確認は、このバージョン作成時点ではまだ行って
いない。**お手数ですが、以前エラーになったパソコンで改めてインストールを試していただき、
結果を教えていただけますでしょうか。**

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)および
[docs/adr/0005-windows-distribution.md](../adr/0005-windows-distribution.md)を参照。

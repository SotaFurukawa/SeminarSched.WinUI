# v0.11.2 (beta)

Status: Draft Release。ユーザーからの文言・レイアウトの大規模な一括指摘（checkpoint 110）への対応。
不具合修正・UI微調整のためNext Version Ruleの既定に従いv0.11.2とした。

## ハイライト

- 「取込み」の表記を、名詞は「取込」、動詞は「取り込む」に統一した。
- ホーム画面: 「Excelで基本情報を編集」→「編集した内容を反映」の順番で操作することがわかるよう
  矢印でつなぎ、残りのボタンは別の行へ分けた。新規プロジェクト作成フォームの「年度」欄の数字が
  右へずれる不具合、「講習区分」と保存プレビューの間の余白が広すぎる不具合を修正した。「一人の
  講師が同時に担当できる生徒数」を「集団授業の日程を考慮する」と切り離し、常に編集できるようにした。
- ①設定: 生徒・講師の状態表示を「有効」「停止」から「在籍中」「卒業・無効」に変更した。
- ②アンケート作成: 「作成手順」の画像をこのWinUI版の画面に差し替えた（保存先パスに含まれる
  個人情報は黒塗り処理済み）。
- ③アンケート取込: 見出し・説明文・ボタン名を整理し、「1対1必須」を他の項目と同じ選択形式に変更した。
- 3.1集団授業クラス・3.2集団授業の受講登録: 説明文を整理し、カレンダー内のコマ表示をクラス名+科目と
  時刻の2行表示に変更した。
- ④時間割編集: 説明文を整理し、出勤不可コマの色をより濃いグレーに変更し、ウィンドウを縦長にした
  ときに生徒名検索欄が潰れる不具合を修正した。
- ⑤時間割自動作成: 説明文を整理し、品質レベル4・5の説明文を実際の探索数に合わせて更新し、品質
  スライダーの目盛り数字1〜5がずれて表示される不具合を修正し、「⑥出力で結果を確認」ボタンを
  追加した。
- ⑥出力: 説明文を整理した。

## 既知の未実装・保留

- 品質プロファイル（`OptimizationProfileCatalog`）のハードウェアtier閾値較正は、実機フィードバック
  次第で今後調整の可能性がある。
- 「+講師を表示」で表示されるアンケート未回答講師のデフォルト表示（○になっている）について、
  該当箇所のロジックを追跡した限りコード上では再現できず、判定を誤って変更するリスクを避けるため
  今回は見送った。実際にどのような講師で発生するか、次回ご確認いただきたい。
- 今回の変更はすべてこの開発機では実際の画面を確認できないため、実機でのご確認をお願いしたい。

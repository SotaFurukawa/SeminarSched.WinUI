# v0.10.0 (beta)

Status: Draft Release。ユーザー要望「同一講師が同一生徒を連続コマで担当するのを避ける/優遇するに
ついて、避ける意味はあまりないと思うので、『考慮しない』と『できるだけ連続にする』にして、新たな
探索方針としてください」（checkpoint 107）への対応。新機能のためNext Version Ruleの既定に従い
v0.10.0とした。

## ハイライト

- ⑤時間割自動作成の「この回だけ探索の方針を変更する」、および「①設定」の「スケジュール設定」
  タブに、新しい探索方針「同一講師×同一生徒の連続コマ」を追加した。既存の⑥「時間帯」の直後、
  従来の⑦「同時に使える座席数」の直前に挿入し、これに伴い従来の⑦は⑧へ繰り下げた。
- 選択肢は「考慮しない（既定）」「できるだけ連続にする」の2択（「避ける」は意図的に設けていない）。
  同じ生徒が同じ講師の授業を複数回受ける場合に、それらの授業を同じ日の隣り合うコマへまとめる
  ことを優遇する。

## 主な変更点

- `SchedulingPolicy`に`TeacherStudentConsecutivePreference`（既定`None`）を追加。既存プロジェクトにも
  ALTER TABLEで列を追加する。
- CP-SATモデルに`BuildTeacherStudentConsecutiveTerms`を追加し、同じ（生徒・講師・日付）の組について、
  その日の隣り合うコマの両方に候補が選ばれた場合へ加点する（既に確定済み・ロック済みの配置が
  隣にある場合も対象に含める）。
- ⑤画面の一時上書きセクション・「①設定」の「スケジュール設定」タブの両方にラジオボタンを追加。

## 既知の未実装・保留

- 品質プロファイル（`OptimizationProfileCatalog`）自体のさらなる見直しは保留中（ユーザーからの
  明示的な要望あり、実装するまで毎回案内する）。
- 新規CP-SATテストで狙った条件（他の条件が同じなら同じ講師で隣接コマにまとめる方を選ぶこと）は
  検証済みだが、実機での見た目・操作感の確認は未了。実機でご確認いただきたい。

詳細は[機能同等性台帳](../FEATURE_PARITY.md)を参照。

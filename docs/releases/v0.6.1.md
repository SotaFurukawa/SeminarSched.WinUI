# v0.6.1 (beta)

Status: Draft Release。v0.6.0公開後、実際に使ってみたユーザーからのフィードバック2件（checkpoint 88）をまとめた区切り。いずれもbug fix / minor changeのため、Next Version Ruleの既定に従いv0.6.1とした。

## ハイライト

- ⑤時間割自動作成でCPUに大きな負荷がかかっていた問題に対応した。CP-SATの探索並列数に上限を設け、論理コアを専有し続けないようにした。
- ⑤の自動作成ゲージが、1つの戦略が終わるたびに一気に飛ぶように動いていた見た目を、滑らかに変化するように改善した。

## 主な変更点

### CP-SAT探索のCPU使用率上限
- v0.6.0で追加した「持ち時間いっぱいまで試行を繰り返す」探索戦略により、CP-SATの並列探索設定（従来はOR-Tools任せで論理コアを全て使い切る設定）が、長時間にわたりCPUを専有し続ける結果になっていた。
- 論理コア数の半分（下限2）までに制限するようにした。1並列まで絞ると実データで解自体が出にくくなることが分かっているため、そこまでは絞っていない。

### 自動作成ゲージの滑らかな表示
- CP-SATが名目の持ち時間よりずっと早く終わる戦略があると、その戦略の進捗表示がわずかしか進んでいないうちに、完了した瞬間に一気にその戦略の満額まで切り替わって見えていた。
- 表示用のパーセンテージを、本来の目標値へ短い間隔（200ミリ秒）で少しずつ近づけるようにし、この段差が目立たないようにした。

## 既知の未実装・保留

- 出力設定の表示項目ON/OFF・ロゴ画像・1ページの日数/講師列数・生徒別改ページ方式は引き続き未実装。
- 授業間隔の均等化・同一科目の連続抑制は、CP-SATの目的関数への近似的なソフト制約であり、常に理想的な結果を保証するものではない（v0.6.0から変更なし）。

詳細は[機能同等性台帳](../FEATURE_PARITY.md)を参照。

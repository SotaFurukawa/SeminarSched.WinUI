# v0.27.0 (beta)

Status: Draft Release。生徒・講師の削除機能を追加する新機能のためminorを上げてv0.27.0とした。

## 変更内容

- **生徒・講師タブに「削除」ボタンを追加した**: 誤ってテストデータを入れてしまった場合など、
  有効・無効（卒業・無効）の切り替えだけでなく、生徒・講師そのものを削除できるようにした。
  一覧の行にカーソルを合わせたときに表示される「変更」の右に「削除」ボタンが並び、クリックすると
  「〇〇を削除しますか？この操作は取り消せません。」という確認ダイアログを経由する（取り消し不可）。
  すでに受講希望が登録されている生徒、すでに時間割へ配置済みの講師は削除できず、「この生徒には
  受講希望が登録されているため削除できません。先に受講希望を削除するか、在籍状態を『卒業・無効』
  にしてください。」のように理由と対処法を示すエラーメッセージを表示する。
- **生徒・講師・科目・通常授業担当設定タブの「変更」ボタンの有効範囲を広げた**: 一覧の行に
  カーソルを合わせてから「変更」（および新設の「削除」）ボタンへカーソルを動かす際、行の背景が
  透明のまま（ヒットテスト対象外）だったため、ボタンへ向かう途中でカーソルが行の外に出たと
  判定されボタンが消えてしまうことがあった。各行のGridに`Background="Transparent"`を設定し、
  行全体を確実にホバー判定の対象にした。
- **アンケート取込の受講希望一覧で、通常担当講師・第1〜第3希望講師を苗字のみ表示するようにした**:
  列幅を抑えられるようになったため、列数が多く右側にはみ出していた問題と、見出し「最大連続上書き」
  「空きコマ上書き」が2行に折り返されていた問題の両方を解消した。
- **受講希望一覧の「最大連続コマ数」「空きコマ許可」列の表示を変更した**: 上書きが指定されていない
  場合に「既定値」「指定なし」というプレースホルダーを表示するのではなく、実際にその受講で使われる
  値（生徒本人の設定）をそのまま数字・「許可」「不許可」で表示するようにした。列見出し・編集欄とも
  「上書き」という語は使わないようにした。

## 検証について

既存の全テスト（計252件）がすべて通過することを確認済み。加えて実機（dev-run）で、①生徒一覧で
新規追加した安全なテスト行の削除（確認ダイアログ→削除→一覧から消える）、②受講希望が登録済みの
生徒の削除を試みるとブロックされ理由付きのエラーが表示されること、③行ホバー時に「変更」「削除」
双方のボタンへ問題なくカーソルを到達できること、④受講希望一覧で通常担当講師・第1〜3希望が苗字の
みで表示され、見出しが1行に収まり、右側のはみ出しが解消されていること、⑤最大連続コマ数・空きコマ
許可の列が実際の値（例: 2・不許可）を直接表示することを確認した。

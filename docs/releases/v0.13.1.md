# v0.13.1 (beta)

Status: Draft Release。v0.13.0の動作確認で見つかった既存バグ（checkpoint112の変更とは無関係）の
修正。bug fixのためpatchを上げてv0.13.1とした。

## 修正内容

- 配置が1件も無い状態（自動作成を一度も実行していない状態）で⑥出力を実行すると、生徒配布・講師
  配布PDFがページを1枚も追加しないままPDFへ保存しようとし、「ページが1枚も無いPDFは保存できない」
  という例外でアプリごとクラッシュしていた不具合を修正した。該当する場合はExcel版と同じ文言
  「出力対象がありません」の案内ページを1枚出力するようにした（Excel版は元々各シートへ無条件で
  スタイル設定用シートを追加していたため、この不具合はPDF版だけで発生していた）。
- 回帰テストを追加し、配置0件の状態で⑥出力全体（`SqliteOutputPackageService.GenerateAsync`）が
  例外を投げずPDFを生成できることを確認した。

詳細は[機能同等性台帳](../FEATURE_PARITY.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

# v0.19.2 (beta)

Status: Draft Release。bug fix・UI調整のためpatchを上げてv0.19.2とした。

## 対応内容（UI調整・不具合修正）

- **プロダクトキー入力欄をGitHubの二段階認証コードのような方式に変更**: 従来の1本の
  テキストボックス（ハイフンも含めて自分で入力）から、12枠（4桁×3グループ、ハイフンは
  区切り表示のみ）の1文字ずつの入力欄へ変更した。1枠入力すると自動的に次の枠へ移動し、
  空の枠でバックスペースを押すと前の枠へ戻って1文字削除する。キー全体をコピー＆ペースト
  した場合は、貼り付け位置から各枠へ自動的に分配する。
- **プロダクトキー入力ダイアログの案内文を変更**: 「プロダクトキーは年度（毎年2月1日）
  ごとに更新が必要です」から、「プロダクトキーを所持していない、または不明な場合は
  契約事業者にお問い合わせください」へ変更した。
- **「Googleフォーム回答の取込」の絵文字アイコンをWinUI標準アイコンへ変更**: 見出し先頭の
  🟦（絵文字）を、ナビゲーションの「③アンケート取込」と同じFontIconへ置き換えた。
- **時間割編集「事前確定・配置一覧・手動配置（通常は使いません）」セクションを削除**:
  ドラッグ＆ドロップによる配置、カードの右クリックメニュー（ロック切替・手動配置の削除）
  で同等の操作ができるため、ほぼ使われていなかったこのセクションを削除した。
- **探索方針をドラッグで並び替えたときに行番号が更新されない不具合を修正**: WinUIの
  ListViewによるドラッグ並び替えは、ドロップ完了イベント（DragItemsCompleted）が発火
  した時点ではまだ内部的な並び順の書き換えが完了しておらず、そこで即座に番号を振り直すと
  移動前の古い順序に対して番号が決まってしまい、見た目の行の並び（ラベル）は正しく
  ドラッグ結果どおりになる一方で、番号だけが移動前の値のまま残っていた（矢印ボタンでの
  並び替えは問題なし）。並び順の書き換えが確実に完了した後で番号を振り直すよう修正した。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

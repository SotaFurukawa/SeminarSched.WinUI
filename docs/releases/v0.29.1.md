# v0.29.1 (beta)

Status: Draft Release。時間割編集の講師列の並び替えと、アンケート取込の受講希望一覧の
列幅・ずれを修正するpatch。

## 変更内容

- **時間割編集（日別グリッド編集）で、その日にちに生徒が配置されている講師を左詰めにした**:
  従来は講師IDの順番で固定だったため、配置が無い講師が間に混ざり、横に長い盤で目的の講師列を
  探しにくかった。配置がある講師を常に左側にまとめ、無い講師は右側へ寄せるようにした（配置の
  有無が同じ講師同士は従来通りの並び順を維持する）。
- **アンケート取込の受講希望一覧で、列の隙間が大きすぎる問題と、ホバー時に列がずれる問題を
  修正した**: 「生徒氏名」「科目名」の列が可変幅のままだったため、ウィンドウが広いときに
  実際の文字列よりずっと広がり、大きな余白に見えていた。また、行にカーソルを合わせたときだけ
  現れる「変更」「削除」ボタンの分、他の列の幅がその都度変化し、見出しと行の列位置がずれて
  見えていた。両方の列を固定幅に変更し、ウィンドウ幅やホバーの有無に関わらず列の位置・幅が
  常に一定になるようにした。

## 検証について

新規テスト1件（配置がある講師が左詰めになることの確認）を含む既存の全テスト（計256件）が
すべて通過することを確認済み。あわせて、前回v0.29.0のバージョン更新時に見落としていた
`RepositoryPolicyTests`の期待値更新漏れ（失敗していたテスト1件）も本バージョンで修正した。

列の見た目・並び替えについては、ビルド成功とコードレベルの確認（ロジックの手作業トレース、
新規テストの通過）のみ行い、実機（dev-run）での画面確認はこのバージョンでは行っていない。
**次回パソコンを使用する際に、以下を目視確認していただきたい:**

1. 「4 時間割編集」で、ある日にちに生徒が配置されている講師の列が左側にまとまって表示されること。
2. 「3 アンケート取込」の受講希望一覧で、生徒氏名・科目名の列の余白が適切になり、行にカーソルを
   合わせても見出しと列がずれないこと。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

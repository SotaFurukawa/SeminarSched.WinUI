# v1.0.0

Status: Release（Draftではなく公開）。ユーザーの明示指示により、開発版表記「-beta」を外した
最初の正式版として提出・公開する。

## このリリースについて

ここまでのv0.0.0〜v0.31.3での段階的な開発（生徒・講師・科目などの基本情報管理、アンケート取込、
集団授業クラス・受講登録、時間割編集、CP-SATによる時間割自動作成、Excel/PDF出力、ライセンス・
アップデート機能など）を経て、ユーザーの明示指示により今回を区切りとして完成品 v1.0.0 として
まとめてリリースする。

直近の変更点（v0.31.3からの差分）:

- 受講希望一覧の列幅調整、「可用性の手動編集」の名称変更（「出席・出勤不可日程の編集」へ）、
  設定画面のライセンス・アップデートボタンの位置調整。

それ以前の主な変更履歴は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)および
[docs/releases/](.)配下の各バージョンのリリースノートを参照。

## 検証について

既存の全テスト（計263件）がすべて通過することを確認済み。

**重要な申し送り:** checkpoint152（v0.29.0）以降のすべてのUI変更・新機能（集団授業の空き時間設定、
自動作成後の入れ替え提案機能、一覧行の取消ボタン、各種列幅・文言調整など）は、ビルド成功と
ユニットテストの通過のみで確認しており、実機（dev-run）での目視確認を行っていない。今回「完成品
として提出する」というユーザーの明示指示によりv1.0.0として公開したが、これらの変更についての
実機確認は済んでいない状態である。実際に配布・使用する前に、一通り実機で操作して見た目・挙動を
確認することを推奨する。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

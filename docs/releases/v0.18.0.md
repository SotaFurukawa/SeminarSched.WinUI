# v0.18.0 (beta)

Status: Draft Release。新機能を含むためminorを上げ、patchを0へ戻してv0.18.0とした。

## 新機能: 講師指導可能科目マトリクスの見出し・左列を固定表示

- 「①設定」の「講師指導可能科目」タブの表を、横にスクロールしても講師ID・講師氏名列が左側に
  固定されたまま、縦にスクロールしても科目見出し行が上側に固定されたままになるようにした
  （Excelのウィンドウ枠固定と同じ操作感）。講師・科目の数が多いプロジェクトでも、どのセルが
  どの講師・科目かを見失わずに編集できる。

## 対応内容（UI調整・不具合修正）

- **探索方針の昇格位置**: 「考慮しない」から値を変更した探索方針が、絶対的な先頭ではなく、
  既に考慮する設定になっている行の直後（＝最初の「考慮しない」行の直前）に挿入されるように
  修正した（例: ①〜③が考慮する設定のとき⑤を考慮するようにすると、⑤だったものが④の位置に
  来る）。
- **探索方針のラジオボタンの横位置が行ごとに揃っていなかった不具合**: 固定幅の選択肢列へ
  変更し、全ての行で選択肢の横位置が揃うようにした。
- **「同時に使える座席数」の位置と名称**: 「①設定」「⑤時間割自動作成」の両方で、独立した
  ⑧番の項目ではなく、「一人の講師が同時に担当できる生徒数」のすぐ下・探索方針の上に配置した。
  名称も「同時に使える座席数上限（0であれば無制限）」に変更した。
- **ホーム画面「オプション機能」の文言**: 「既定値から変更する」という分かりにくいラベルを
  やめ、「一人の講師が同時に担当できる生徒数（既定は2人）」を直接表示するようにした。数値入力
  欄の幅も必要最小限まで狭めた。
- **③アンケート取込「受講希望」フォーム**: 「通常担当講師（任意）」「優先度1〜5」を次の行へ
  移動した。
- **「コマ・開校日」の開校日・休校日カレンダー、「可用性の手動編集」カレンダー**: 内部スクロール
  をやめ、全体をそのまま表示するようにした（ページ自体のスクロールに委ねる）。
- **「設定」画面「アップデート」の見出しと内容が離れていた表示**: 見出しと「アップデートを
  確認」ボタンを同じ行に、状態文言を見出しの直下に配置するレイアウトへ変更した。
- **横幅の広げすぎ**: 前バージョンでページの最大幅制限を撤廃した際、明示的な幅指定のない
  テキストボックス（生徒・講師タブの備考欄や検索欄、出力設定のファイル名規則欄など）が
  ウィンドウ幅いっぱいまで伸びてしまっていたため、それぞれに適切な幅を指定した。

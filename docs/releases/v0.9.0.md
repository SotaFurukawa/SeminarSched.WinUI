# v0.9.0 (beta)

Status: Draft Release。ユーザー要望「⑤自動作成の探索方針について、③と④の間に、『講師の出勤日』、
『考慮しない、できるだけ減らす、分散する』を追加してほしい」への対応（checkpoint 104）。新機能の
ためNext Version Ruleの既定に従いv0.9.0とした。

## ハイライト

- ⑤時間割自動作成の「この回だけ探索の方針を変更する」、および「①設定」の「スケジュール設定」
  タブに、新しい探索方針「講師の出勤日」を追加した。既存の③「生徒の授業日」の直後、従来の④
  「1コマあたりの生徒の対応人数」の直前に挿入し、これに伴い従来の④⑤⑥は⑤⑥⑦へ繰り下げた。
- 選択肢は既存の③と同じ「考慮しない（既定）」「できるだけ減らす（同じ日にまとめる）」「分散する」
  の3択。①「一日当たりの講師人数」（学校全体で1日に登場する講師の"人数"を絞る、日ごとの視点）
  とは異なる軸で、こちらは講師1人あたりが何日出勤することになるか（講師ごとの視点）を扱う。

## 主な変更点

- `SchedulingPolicy`に`TeacherAttendanceDaysPreference`（既定`None`）を追加。既存プロジェクトにも
  ALTER TABLEで列を追加する。
- CP-SATモデルに`BuildTeacherDayDispersionTerms`を追加し、既存の生徒版（`BuildDayDispersionTerms`）
  と同じ仕組み（Concentrateは出勤日数が多いほど減点、Spreadは加点、Noneは項自体を生成しない）を
  講師×開講日の単位で適用した。
- ⑤画面の一時上書きセクション・「①設定」の「スケジュール設定」タブの両方にラジオボタンを追加。

## 既知の未実装・保留

- 品質プロファイル（`OptimizationProfileCatalog`）自体のさらなる見直しは保留中（ユーザーからの
  明示的な要望あり、実装するまで毎回案内する）。
- 新規CP-SATテストで狙った条件（他の条件が同じなら出勤日数を減らす方を選ぶこと）は検証済みだが、
  実機での見た目・操作感の確認は未了。実機でご確認いただきたい。

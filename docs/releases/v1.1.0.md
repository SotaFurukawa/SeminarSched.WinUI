# v1.1.0

Status: Release（アップデートの確認で新しいバージョンが見つかった場合、アプリ内から直接
アップデートできるようにした新機能）。

## 変更内容

- **「アップデートを確認」で新しいバージョンが見つかった場合、これまでは「ダウンロードページを
  開く」ボタンでブラウザのリリースページへ誘導していたが、「アップデートを行う」ボタンへ
  置き換えた。** 押すと、アプリ内でインストーラー（Setup.exe）を直接ダウンロードし、ダウンロードが
  終わるとそのまま起動する。
  - ダウンロード中は進捗（%）を表示する。
  - Setup.exeは管理者権限が必要なため、起動するとWindowsのUAC確認画面が表示される。「はい」を
    選んで進めると、これまでどおりの手順（証明書の信頼登録・インストール）が自動的に行われ、
    このアプリ自身も更新の途中で自動的に終了する。
  - 週に1度の自動アップデート確認で新しいバージョンが見つかったときに出る案内画面も、同じ
    「アップデートを行う」ボタンに統一した。
- 万一、リリースにインストーラーの資産が見つからない場合（通常は発生しない想定）は、従来どおり
  リリースページをブラウザで開く動作へ自動的に切り替わる。

## 検証について

既存の全テスト（計266件）がすべて通過することを確認済み。アップデートURLの抽出ロジックは
ユニットテストで確認した。実際のダウンロード→UAC昇格→インストール完了までの一連の流れは、
実機でアップデート通知を受け取った際に確認する必要があり、本バージョン作成時点ではまだ未検証。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)および
[docs/adr/0007-auto-update-check.md](../adr/0007-auto-update-check.md)を参照。

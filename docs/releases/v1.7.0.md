# v1.7.0

Status: Release

## 変更内容

### 1. 講師の一日最低コマ数を設定できるように

「1 プロジェクト設定」の「スケジュール設定」タブ、「同時に使える座席数上限」の下に「講師の一日
最低コマ数」（既定1、1〜10）を追加した。2以上に設定すると、その日に1コマでも配置される講師は、
必ずその数以上のコマが確定で配置されます（その講師をその日まったく配置しないこと自体は常に
可能です）。

自動作成（5 時間割自動作成）のハード制約として実装しており、「1コマだけ出勤させるのは申し訳ない」
といった運用上の都合に対応できます。

### 2. 自動作成の評価スコアを「6 出力」ページで確認できるように

「6 出力」ページの、既存の出力ボタン・ファイルを開くボタンの下に「直近の自動作成の評価スコア」
欄を追加した。表示項目:

- 未配置コマ数
- 通常担当講師等の希望を満たせなかった件数
- 講師希望との不一致ペナルティ
- 生徒の授業日の集中度（延べ重複回数）
- 授業間隔の乱れ具合
- その他のソフト制約ペナルティ
- 総合スコア（内部計算用の目安）

いずれも値が小さいほど質の高い時間割であることを示す。自動作成を一度も実行していないプロジェクト
では、この欄自体を表示しない。「5 時間割自動作成」を実行し直すと内容が更新される。

これらは、以前から戦略同士の比較のために内部で計算されていたものの、実行結果としては保存・表示
されていなかったスコアを、プロジェクトのデータ（OptimizationRunテーブル）へ保存して読み出せる
ようにしたもの。v1.6.1以前に実行した結果は簡易な内容（未配置コマ数のみ）しか保存されていないため、
一部の項目が0と表示されるが、次に自動作成を実行し直せば以降は全項目が正しく保存される。

詳細は[ADR 0012](../adr/0012-min-daily-lessons-and-score-display.md)参照。

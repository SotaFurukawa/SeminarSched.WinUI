# v0.3.2 (beta)

Status: Draft Release。v0.3.1公開後、checkpoint 80（Inno Setupインストーラ）・81（集団授業表示・学年一括繰り上げ・科目略称修正・タスクバー通知簡素化）・82（出力設定画面・プロジェクト別出力フォルダ・講師別一括ファイル・PDF全面刷新）をまとめた区切り。バージョン番号はユーザーが明示的に「0.3.2」と指定した。

## ハイライト

- ①設定に新規タブ「出力設定」を追加し、PDFの用紙サイズ(A3/A4)・向き・余白、出力ファイル名の規則、休校日・勤務不可コマ・集団授業の塗り色をプロジェクトごとに設定できるようにした。
- ⑥出力の出力先を、既定フォルダの直下にプロジェクトごとの専用フォルダを作る構成に変更し、複数プロジェクトの出力が混在しないようにした。ファイル名も規則に基づいて統一（例:「2026年度夏期講習-全体時間割.xlsx」）。帳票名・ファイル名を「季節講習時間割」から「全体時間割」に変更した。
- 新しい帳票「講師配布用講師別時間割(一括)」を追加。従来の講師ごとの個別ファイルとは別に、全講師分を1ファイルにまとめ、各ページに「{講師名}t用」のラベルを付けた。2ページ単位でまとめて印刷する運用を想定し、担当生徒数が奇数の講師の直後には空白ページを自動挿入する。
- PDF出力をExcel出力と同じ見た目（フォント・色・レイアウト）に全面刷新した。集団授業の黒塗り表示や月・曜日・日の配色もPDFに反映される。
- Inno Setupベースの単一インストーラ(Setup.exe)を追加し、Draft ReleaseからPython版と同じ形式でインストールできるようにした（詳細はv0.3.1のハイライト参照）。
- 3.1集団授業クラスのカレンダー表示にクラスの科目を追加、共通名簿に「学年を一括で繰り上げる」機能を追加、科目の略称が未入力でも必ず一文字になるよう修正、集団授業を受講する生徒の時間帯を個別指導ページ上でも黒塗り「集団」表示するようにした。

## 主な変更点

### 出力設定画面（新規）
- ①設定の「出力設定」タブから、PDFの用紙サイズ・向き・余白(mm)、ファイル名規則（`{project}`/`{report}`/`{date}`トークン）、休校日・勤務不可コマ・集団授業の3色（#RRGGBB）をプロジェクトごとに設定・保存できる。値は⑥出力のExcel/PDF双方に反映される。
- 表示項目のON/OFF・ロゴ画像・1ページの日数/講師列数・生徒別改ページ方式は、既存の週単位固定レイアウトとの設計上の衝突が大きいため今回は対象外とした（別途相談の上で対応予定）。

### 出力フォルダ・ファイル名・帳票名
- 出力先を`<既定フォルダ>\<プロジェクトタイトル>\SeminarSched_Output_<日時>\`という構成に変更し、プロジェクトごとにフォルダが分かれるようにした。
- ファイル名を`{project}-{report}`（既定）のパターンで統一。プロジェクトのタイトル表記も「2026夏期講習」から「2026年度夏期講習」に変更した。
- 全体時間割の帳票名・ファイル名を「季節講習時間割」から「全体時間割」に変更した。

### 講師配布用講師別時間割(一括)（新規帳票）
- 全講師分を1つのExcel/PDFにまとめた版を追加。各生徒ページの左上に「{講師名}t用」のラベルを表示し、どの講師の束か一目で分かるようにした。
- 担当生徒数が奇数の講師の直後には空白シート/ページを1枚挿入し、2ページ単位で印刷しても講師の境界がずれないようにした。

### PDF出力の全面刷新
- 生徒配布・講師配布（学年別・講師別、単独・一括とも）・全体時間割のPDFを、Excel版と同じフォント・配色・レイアウトで作り直した。タイトルの黒地白文字、月・曜日・日の見出し配色、学力テスト行、集団授業の黒塗り「集団」表示まで再現している。
- タイトル用フォント「BIZ UDPMincho Medium」はPDFライブラリの制約（TrueType Collection形式を読み込めない）により、本文と同じ「HG丸ゴシックM-PRO」を太字で代用している。
- 用紙サイズ・向き・余白は出力設定から反映され、曜日ごとの列幅は用紙に応じて均等に自動調整される。

### その他
- 3.1集団授業クラスのカレンダーセル表示を「クラス+時間」から「クラス+科目+時間」に変更。
- 共通名簿に「学年を一括で繰り上げる」ボタンを追加。新しい季節講習を迎える際に在籍中の生徒全員の学年を1つ繰り上げ、高3だった生徒は既卒として在籍停止（グレー表示）にする。現在開いているプロジェクトへは自動反映しない。
- 科目の略称（一文字）がShortName未入力の場合、従来はフルネームへフォールバックしていたが、Python版と同様に表示名から一文字を推定するアルゴリズムに変更した。
- タスクバー通知について、出力完了時の点滅は維持しつつ、右下の常駐オレンジ丸バッジを廃止した。
- Python版と同じ形式のInno Setupインストーラ(Setup.exe)をGitHub Releaseへ添付する運用を開始した。

## 既知の未実装・保留

- 出力設定の表示項目ON/OFF・ロゴ画像・1ページの日数/講師列数・生徒別改ページ方式は未実装（設計上の衝突のため保留）。
- 集団授業の受講時間帯を④時間割編集・⑤時間割自動作成の制約（個別指導との二重予約回避）へは連携していない（⑥出力での表示のみ）。
- v0.3.1のリリースノート記載の「デザイン設定」テンプレートシートは引き続き実験的機能のまま。
- Setup.exeの`PrivilegesRequired=lowest`が、証明書を一度も信頼したことが無い別PCでも成立するかは未確認。

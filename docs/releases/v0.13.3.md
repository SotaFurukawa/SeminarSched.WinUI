# v0.13.3 (beta)

Status: Draft Release。ユーザーからの4件の指摘への対応（UI微調整・不具合修正）。
bug fix/UI微調整のためpatchを上げてv0.13.3とした。

## 修正内容

- **checkpoint109の誤りを修正**: 「円形のゲージにして文字を消してほしい」という要望は、⑤時間割
  自動作成の**ページ内部**の進捗表示ではなく、**左側ナビゲーションペイン下部（①設定の少し上に
  常設される「⑤自動作成 実行中」インジケーター）**を指していたと判明。⑤ページ自体の進捗表示は
  元のプログレスバー＋段階/戦略名テキスト＋残り時間テキストへ戻し、ナビゲーションペインの常設
  インジケーターの方を円形ゲージ（中央にパーセンテージのみ表示）へ変更した。
- **講師ID・生徒IDの表示を①設定以外から削除**: 講師ID・生徒IDは内部処理でのみ使用し、画面表示は
  ①設定に限定する方針とした。④時間割編集の講師列見出し・配置一覧・差分表示、③アンケート取込の
  生徒/講師選択欄、3.1集団授業クラスの担当講師選択欄から、ID（例:「T-001」）の表示を削除し、
  氏名のみを表示するようにした。
- **④時間割編集の行の高さを拡大**: 1コマあたりの最小の高さを56pxから112pxへ（約2倍）拡大した。
- **左ナビゲーションのアイコンを変更**: ①設定・②アンケート作成・③アンケート取込・3.1集団授業
  クラス・④時間割編集の5項目のアイコンを、ユーザー指定のグリフへ変更した。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

# v1.4.4

Status: Release

## 変更内容

ユーザーが実際に生成したGoogleフォームのスクリーンショットをもとに、3件対応した。

### ①「作成手順」ガイドの画像を実際のスクリーンショットへ差し替え

手順1-2枚目（保存後、「保存先を開く」ボタンが表示された状態）の画像を、ユーザーから提供された
実際のスクリーンショットへ差し替えた。v1.4.0で追加した「中学受験と中学受験以外を分ける」
チェックボックスが写った、現行仕様に即した内容になった。

### ②v1.4.3の並び順修正を差し戻し

v1.4.3で、「中学受験をしますか？」を「他学年の受講」チェックより前に表示するため、共通の
「他学年」チェックを学校段階ごとのページへ複製し、タイトルへ「（小学校）」等の付記を加えた。
しかし実際に生成されたフォームを見ると、この付記が回答者にとって不自然に見えるため、差し戻す
ことにした。「中学受験をしますか？」自体は今まで通り小学校ページに残り、結果的に「他学年の
受講」チェックより後に表示される状態へ戻る。v1.4.3で見つけて修正した不具合
（`elementaryPage`に遷移先指定が無く、既定動作で誤って中学校ページへ連続表示されていた）は
今回の差し戻しと無関係なため、そのまま維持した。

### ③実装説明の文言を削除

小学校・中学校・高校それぞれの受講教科ページの説明文にあった「学校区分は○○として自動的に
扱います。」という一文を削除した。アプリ内部の自動判定ロジックを説明する文言で、回答者（保護者
等）から見ると不自然だったため。

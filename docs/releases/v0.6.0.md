# v0.6.0 (beta)

Status: Draft Release。v0.5.0公開後、checkpoint 86（コマ並び替えボタン修正、共通名簿Excelのプルダウン選択、時間割作成の残り時間再修正・連続探索戦略、講師名の苗字統一、全体時間割の体裁修正）・checkpoint 87（生徒ごとの授業間隔の均等化・同一科目の連続抑制）をまとめた区切り。いずれも新機能追加を含むため、Next Version Ruleの既定に従いv0.6.0とした。

## ハイライト

- ①コマ設定の▲▼並び替えボタンが効かない不具合を修正した。
- ホーム画面に、共通名簿Excelの実際の最終更新日を表示するようにした。
- 共通名簿Excel（生徒・講師_基本情報.xlsx）の「通常授業」「講師対応科目」シートで、生徒・講師・科目をプルダウンから選択できるようにした（選択するとID列が自動入力される）。
- ⑤時間割作成の「残り目安時間」を、名目時間からの逆算ではなく実際の進み具合から推定するようにした。高品質・最高品質で持ち時間を使い切れない問題に対応する、持ち時間いっぱいまで試行を繰り返す新しい探索戦略を追加した。
- 帳票の講師名表示を全て苗字のみに統一した。
- 全体時間割の不要なタイトル行を削除し、配置カードにPython版相当の色付け（1対1・ロック・手動変更）を追加した。
- ⑤時間割作成で、生徒ごとの授業間隔ができるだけ均等になるように、また同じ科目の授業が連続しにくくなるように、新しい探索の評価基準を追加した。

## 主な変更点

### ①コマ設定・並び替えボタンの修正
- 隣接する2件だけの順序値を入れ替える方式では、既存データに不整合な順序値が残っていると見た目上の並びが変わらないことがあったため、移動のたびにリスト全体を振り直す方式に変更した。

### ホーム画面: 共通名簿Excelの最終更新日表示
- 保存先パスの下に、Excelファイルの実際の最終更新日時を表示するようにした。

### 共通名簿Excelのプルダウン選択
- 「通常授業」「講師対応科目」シートの生徒・講師・科目列に、セル内ドロップダウンと、選択に応じてID列を自動入力する数式を追加した（Python版のxlsxwriter data validation相当）。

### ⑤時間割作成: 残り時間表示・持ち時間を使い切る探索戦略
- 「残り目安時間」を、直近の完了済み進捗から実測ペースを求めて推定するようにした（データ不足時は「計算中…」と表示）。
- 高品質・最高品質のCP-SAT部分修復・最終仕上げ探索を、固定回数の試行ではなく持ち時間を使い切るまで独立した試行を繰り返す方式に置き換えた。

### 帳票: 講師名を苗字のみに統一
- 講師配布用講師別時間割(一括)のラベル・ファイル名、未配置一覧、警告一覧を含む全帳票で、講師名を苗字のみで表示するようにした（同姓でも名で区別しない）。

### 全体時間割の体裁修正
- 週シート1行目の不要な「全体時間割」タイトル行を削除した。
- 配置カードにPython版のstyle_rules相当（1対1・ロック・手動変更）の背景色を追加した。

### ⑤時間割作成: 授業間隔の均等化・同一科目の連続抑制
- 生徒ごとに、開講日数÷合計授業回数を理想的な間隔とみなし、授業日ができるだけその間隔に近くなるように探索の評価基準へ追加した。
- 受講希望（科目）ごとにも同じ考え方を適用し、同じ科目の授業が連続して固まりにくくなるようにした（完全な交互配置を保証するものではない）。

## 既知の未実装・保留

- 出力設定の表示項目ON/OFF・ロゴ画像・1ページの日数/講師列数・生徒別改ページ方式は引き続き未実装。
- 授業間隔の均等化・同一科目の連続抑制は、CP-SATの目的関数への近似的なソフト制約であり、常に理想的な結果を保証するものではない。

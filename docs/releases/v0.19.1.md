# v0.19.1 (beta)

Status: Draft Release。v0.19.0のbug fixのためpatchを上げてv0.19.1とした。

## 不具合修正

- **⑤時間割自動作成の探索方針の一時変更が、ページを離れて戻ると並び順以外の選択内容が
  リセットされる不具合を修正**: v0.19.0で「ページを離れても一時変更を保持する」機能を
  追加したが、復元処理（`SchedulingPolicyRowsController.LoadFromSaved`/`Load`）が
  `ObservableCollection`を入れ替えるだけで、並び替え時に使っているコンテナ再構築
  （`ItemsSource`の張り直し）を行っていなかった。そのため、WinUIのListViewがRadioButton
  コンテナを再利用する際にOptionLoadedが再発火せず、並び順は正しく復元される一方で、
  一部の行のラジオボタンの選択状態（丸印）が別の行の古い状態を引き継いで表示されていた。
  復元処理でもコンテナを再構築するよう修正し、並び順・選択状態の両方が正しく復元される
  ことを確認した。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

# v0.4.0 (beta)

Status: Draft Release。v0.3.2公開後、checkpoint 83（④時間割編集中の外部変更検出、Googleフォーム作成キットの整理、ホーム/設定画面の文言・操作性改善、「デザイン設定」テンプレートシートの正式採用）をまとめた区切り。checkpoint83は新機能追加を含むため、Next Version Ruleの既定に従いv0.4.0とした。

## ハイライト

- ④時間割編集中に、プロジェクトのデータが他の経路（Excelでの基本情報反映など）で変更されていないかを検出するようにした。変更を検出した場合は書き込みを中止し、最新の内容へ自動的に読み込み直した上で警告を表示する。
- Googleフォーム作成キットから講師指導可能科目用（3本目のApps Script）を廃止し、生徒用・講師用の2本のみを生成するようにした。講師の指導可能科目は共通名簿Excelの「講師対応科目」で管理する。
- Googleフォーム作成手順のポップアップを、手順一覧＋詳細表示のウィザード形式に刷新した。
- v0.3.1で実験的機能として追加した「デザイン設定」テンプレートシート（生徒配布・講師配布xlsxの見た目を校舎側でカスタマイズできる機能）を、実機評価の結果を受けて正式機能として採用した。
- ホーム画面・設定画面の文言や操作性を多数改善（後述）。

## 主な変更点

### ④時間割編集中の外部変更検出（新規）
- `IScheduleEditorService.GetDataVersionAsync`が、プロジェクトファイル本体とWALサイドカーファイルの最終更新時刻を基にした軽量な「指紋」を返すようになった。
- ④時間割編集画面は読み込み時にこの値を保持し、手動配置・削除・ロック・リセット・出勤可否変更・Undo/Redoなど、あらゆる書き込み操作の直前に再取得して比較する。
- 値が変わっていた場合は書き込みを行わず、Undo/Redo履歴をクリアした上で最新の内容へ自動的に読み込み直し、「プロジェクトのデータが外部で変更されました」という警告を表示する。

### Googleフォーム作成キットの整理
- 講師指導可能科目用のGoogleフォーム作成キット（`create_teacher_subject_questionnaire.gs`）を廃止した。②アンケート作成では生徒用・講師用の2本のみを生成する。
- ②アンケート作成の説明文を「設定した開校日・コマ・科目から、生徒用・講師用のGoogleフォーム作成キットを作成します。フォーム回答(Google spreadsheet)を「3.アンケート取込」でそのまま取り込むことができます。」に変更した。
- 講師の指導可能科目は、共通名簿Excel（生徒・講師_基本情報.xlsx）の「講師対応科目」で校舎側が直接管理する運用に一本化した。

### Googleフォーム作成手順ポップアップの刷新
- 縦一列に手順カードを並べるだけの表示から、左に手順一覧（番号バッジ・タイトル）、右に選択中の手順の詳細（説明・スクリーンショット・補足）を表示するウィザード形式に変更した。
- 上部に進捗バーと「手順X/10」表示、下部に「前の手順／次の手順」ボタンを追加し、一覧から任意の手順へ直接ジャンプすることもできる。

### 「デザイン設定」テンプレートシートの正式採用
- v0.3.1で「良ければ採用、微妙なら廃止」という前提で追加した機能について、実機評価の結果「良かった」との判断を受け、コード・出力されるxlsxのシート見出し双方から「実験的機能」の表記を削除した。機能自体（校舎がシートを編集して保存すると次回出力で読み戻される）に変更はない。

### ホーム画面
- 共通名簿カードのタイトルを「生徒講師基本情報・通常授業担当情報」に変更し、説明文をより分かりやすい表現に変更した。
- バックアップ復元時の注意文を簡潔な表現に変更した。
- 「最近使ったプロジェクト」の各行に「プロジェクトを開く」ボタンを追加した（行自体をクリックして開く操作は引き続き利用できる）。
- 「新しい講習プロジェクト」カードのレイアウトを整理し、「オプション機能」という見出しを新設した（今後増える可能性のあるオプション機能の先頭として、集団授業の日程を考慮する設定を配置）。

### 設定画面
- 「プロジェクト」タブを削除した。このタブにあった、現在のプロジェクトの受講希望データをExcelで一括編集する機能（共通基本情報Excelの出力・取込み）は、③アンケート取込みで十分との判断により削除した。
- 生徒・講師・科目・コマの「有効」チェックボックスが、保存ボタンを押さずにチェックの変更だけで即座に保存されるようにした。
- 開校日・休校日カレンダーのボタンを「休校日を全て選択」「開校日を全て選択」「○曜日を選択」に変更した。
- コマ設定でドラッグ操作による並び替えが保存されない不具合を修正した（並び替え時に必要な処理が一部欠けていたため）。

## 既知の未実装・保留

- ①アンケート旧形式のテンプレート出力機能、④匿名サンプルプロジェクト作成は、ユーザー判断により対応不要とした。
- 設定画面から削除した受講希望のExcel一括編集機能は、③アンケート取込みで代替できるとの判断により復活の予定なし。
- 出力設定の表示項目ON/OFF・ロゴ画像・1ページの日数/講師列数・生徒別改ページ方式は引き続き未実装（v0.3.2から変更なし）。

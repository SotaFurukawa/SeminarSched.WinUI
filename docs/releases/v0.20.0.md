# v0.20.0 (beta)

Status: Draft Release。新機能を含むためminorを上げ、patchを0へリセットしてv0.20.0とした。

## 新機能

- **プロダクトキー認証成功時に成功画面を表示**: 正しいプロダクトキーが入力されると、
  入力フォームの代わりに「Success」の文字と緑色のチェックマークを1秒ほど表示してから、
  自動的にホーム画面へ進むようにした。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

## 検証について

一時的な別パッケージIDの実機ビルドで、①正しいキーを入力して成功画面が表示されたのち自動的に
ホーム画面へ進むこと、②誤ったキーを入力した場合は従来どおりエラーメッセージが表示され入力欄が
リセットされること、の両方をスクリーンショットで確認してから出荷した。検証用のテスト
パッケージ登録は確認後に削除済み。

このversionのGitHub ReleaseはDraftとして作成する。

# v0.13.6 (beta)

Status: Draft Release。ユーザーからの依頼（アイコン再作成・アプリ表示名変更）への対応。UI微調整のため
patchを上げてv0.13.6とした。

## 対応内容

- **アプリアイコンの作り直し**: ユーザーから提供されたisometricなブロック意匠のSVGを元に、全アイコン
  アセットを作り直した。SVGをheadless Chromeで2048x2048の高解像度PNGへラスタライズし、そこから
  `System.Drawing`の高品質な補間（HighQualityBicubic）で各サイズへダウンサンプルすることで、
  16px等の小さいサイズでも輪郭がガビガビにならないようにした。`AppIcon.ico`
  （16/20/24/32/40/48/64/96/128/256の10解像度）、`Square150x150Logo`、`Square44x44Logo`
  （`scale-200`・`targetsize-24_altform-unplated`・`targetsize-48_altform-lightunplated`）、
  `StoreLogo`、`LockScreenLogo`は新アイコンをそのまま全面表示する構図とした（旧デザインは
  「時間割」の文字を正方形アセットにも焼き込んでいたため、極小サイズで文字が判読不能になり
  ガビガビの一因になっていたと判断し、正方形アセットからは文字を除去した）。`Wide310x150Logo`と
  `SplashScreen`は、アイコン＋「ShikiWari」ワードマークを横に並べた構図で作り直した。
- **アプリ表示名を「ShikiWari」に変更**: WinUI版の正式名称（リポジトリ名・Solution名・namespace・
  `%LOCALAPPDATA%`配下の設定/ログ/Workspaceフォルダ名等の内部識別子）は`SeminarSched.WinUI`の
  ままとし、エンドユーザーに見える表示名のみを「ShikiWari」に変更した。対象は`Package.appxmanifest`
  の`DisplayName`、ウィンドウタイトル／タイトルバー、アプリ情報画面のアプリ名見出し、インストーラの
  ウィザードタイトル・スタートメニューのグループ名/ショートカット名・製品名。インストーラの内部
  識別子（インストール先フォルダ名、`.msix`/`.cer`ファイル名、ログファイル名、パッケージID）は
  変更していない。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

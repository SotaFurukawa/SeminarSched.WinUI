# v1.3.0

Status: Release（通常授業担当設定で、同じ生徒・科目でも通常担当講師が違えば複数登録できるように
した新機能。あわせて科目の略称の文字数制約を撤廃）。

## 変更内容

- **通常授業担当設定（0 基本情報設定／1 プロジェクト設定）で、同じ生徒・科目でも通常担当講師が
  異なれば複数行を登録できるようにした。** これまでは同じ生徒・科目の行は常に1行に上書きされて
  しまい、週に2回同じ科目を受講するが曜日によって担当講師が異なる生徒を表現できなかった。
  - 優先度が最も高い行が「通常担当講師」として、残り（最大3件）が優先度順に「第1〜3希望講師」
    として、受講希望アンケート取込み時に自動的に引き継がれるようになった。時間割自動作成は
    これらすべてを候補として使うため、「通常担当講師をできるだけ使い、必要に応じて希望講師へ
    フォールバックする（コマごとに担当講師が変わることもある）」という動作になる。
  - 共通名簿Excelの「通常授業」シートで、同じ生徒・科目・異なる通常担当講師の行を複数入力しても、
    取込みエラーにならなくなった（通常担当講師まで完全に一致する行だけ、引き続き1行へまとめる）。
  - 既存のプロジェクトファイルも、開いたときに自動的に新しい形式へ移行される（既存データは
    失われない）。
- **科目の略称（0 基本情報設定／1 プロジェクト設定の「科目」タブ）について、文字数の制約を
  撤廃した。** これまでは1文字しか入力できず、IME変換の途中（ひらがな2文字以上から漢字1文字へ
  変換する前の状態）で入力が止まってしまい、実質ひらがな1文字しか入力できていなかった。文字数の
  制限自体を無くし、好きな文字数で入力できるようにした。

## 検証について

既存の全テスト（計271件、うち新規4件）がすべて通過することを確認済み。新規テストは、同じ生徒・
科目で通常担当講師が異なる複数行を保存・取込みできること、既存プロジェクトファイルの自動移行、
受講希望アンケート取込み時に優先度順で通常担当講師・第1希望講師へ正しく引き継がれることを検証
している。「0 基本情報設定」画面での実機UI確認は、この開発環境のスクリーンショット手段に問題が
あり、本バージョン作成時点ではまだ行えていない。

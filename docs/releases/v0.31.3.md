# v0.31.3 (beta)

Status: Draft Release。受講希望一覧の列幅再調整、名称変更、設定画面のボタン位置調整を含むpatch。

## 変更内容

- **受講希望一覧（③アンケート取込）の「生徒氏名」「科目名」の列幅を、それぞれ約半分に縮めた**:
  まだ隙間が広すぎるという指摘を受け、さらに縮小した。あふれる場合は「...」で省略表示する。
- **「可用性の手動編集」の名称を「出席・出勤不可日程の編集」に変更した**。
- **設定の「ライセンス」「アップデート」のボタン位置を調整した**: 見出しとボタンの間に余白を
  作り、ボタンを右へ移動した（左端・右端の揃いはそのまま維持）。

## 検証について

既存の全テスト（計263件）がすべて通過することを確認済み（見た目・文言のみの変更のため新規テストは
追加していない）。実機（dev-run）での画面確認はこのバージョンでは行っていない。**次回パソコンを
使用する際に、以下を目視確認していただきたい:**

1. 「3 アンケート取込」の受講希望一覧で、生徒氏名・科目名の列幅と、文字があふれた際の「...」表示。
2. 「出席・出勤不可日程の編集」という名称に変わっていること。
3. 「設定」のライセンス・アップデートのボタン位置（ご希望の間隔に近いか、ずれていればお知らせ
   ください。ディスプレイの表示倍率によって見え方が変わる可能性があります）。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

# v0.5.0 (beta)

Status: Draft Release。v0.4.0公開後、checkpoint 84（時刻選択UIの刷新、3.1/3.2タブの表示制御、科目略称バグの根本修正）・checkpoint 85（担当講師優先度5の候補制限、進捗パーセンテージの計算方式変更、高品質帯の多重近傍探索）をまとめた区切り。いずれも新機能追加を含むため、Next Version Ruleの既定に従いv0.5.0とした。

## ハイライト

- 時間割出力で科目名が一文字の略称にならない不具合の根本原因を特定・修正した。既存プロジェクトの壊れたデータも次にアクセスした時点で自動的に直る。
- ①コマ設定・3.1集団授業クラスの時刻入力を、5分刻みの選択肢を持つ入力欄に変更した。
- 3.1/3.2のナビゲーション項目を、集団授業を有効にしたプロジェクトを開いているときだけ表示するようにした（従来は常時表示されていた不具合を修正）。
- ⑤時間割自動作成で、担当講師優先度5の受講希望は、通常担当講師の出勤可能コマ数が足りる限り他の講師を使わないようにした。第1希望講師は通常担当講師を選ぶと自動的に初期値として補われる。
- ⑤の進捗パーセンテージを、経過時間ではなく実際に完了した探索の割合から計算するようにし、高品質帯で早く終わっても数%から100%へ急に飛ぶ表示を解消した。
- 高品質・最高品質で、同じ探索を長く待つのではなく、異なる乱数近傍を持つ部分修復の試行数を増やした。

## 主な変更点

### 科目略称が一文字にならない不具合の修正
- 共通名簿Excelの「科目」取込みが、新規科目の略称へ「表示名をそのまま切り詰めた値」を入れてしまっていたのが原因（このシートには略称の列自体が無い）。新規科目の略称は表示名から正しく1文字を自動推定するようにし、再取込み時に既存科目の略称を上書きしないようにした。
- 科目の略称は「空欄かちょうど1文字」であることをドメイン層で検証するようにした（従来は10文字以内であれば許可していた）。①設定「科目」タブの略称欄も1文字までに制限した。
- 既にこの不具合で壊れた略称データを持つ既存プロジェクトも、次回アクセス時に自動的に正しい1文字へ修正される。

### 時刻選択UIの刷新
- ①コマ設定・3.1集団授業クラスの開始・終了時刻を、時・分別々の数値入力から、5分刻みの時刻一覧を持つ入力欄（既存の値も表示・編集できる）に変更した。

### 3.1/3.2タブの表示制御
- 「3.1 集団授業クラス」「3.2 集団授業の受講登録」を、集団授業を有効にしたプロジェクトを開いている・作成したときだけ表示するようにした。

### ⑤時間割自動作成: 担当講師優先度5の候補制限
- 担当講師優先度5の受講希望は、通常担当講師の出勤可能コマ数が必要回数以上ある限り、候補を通常担当講師・第1〜第3希望講師だけに絞り込むようにした。出勤可能コマ数が足りない場合は、従来通り他の講師も候補に残す。
- 第1希望講師は、通常担当講師を選ぶと未設定の場合に限り自動的に同じ講師が初期値として補われるようにした。
- 担当講師優先度による通常担当講師の最低保証割合を、優先度が1下がるごとに30ポイントずつ下がる目安（5→100%・4→70%・3→40%・2→10%）に変更した。

### ⑤時間割自動作成: 進捗パーセンテージの計算方式変更
- 進捗パーセンテージを、経過時間と品質レベルの名目上限時間の比率ではなく、計画済みの探索のうち実際に完了・進行中の割合から計算するようにした。CP-SATが証明済み最適解に達して名目時間よりずっと早く終わることが多く、従来の経過時間ベースでは数%のまま止まって終了の瞬間に100%へ飛ぶ表示になっていた。

### ⑤時間割自動作成: 高品質・最高品質の多重近傍探索
- 高品質・最高品質の部分修復（近傍探索）を、1回だけでなく異なる乱数シードによる複数回の試行に増やした（高品質は3回、最高品質は5回）。最高品質の最終仕上げ探索も2回に増やした。
- CP-SATは証明済み最適解に達すると持ち時間を残したまま終了するため、同じ探索を長く待たせるより、異なる近傍を複数回試すほうが改善の見込みが立つとの判断による。ただし、対象データの規模によっては依然としてすぐ収束することもあり、必ず結果が良くなるとは限らない。

## 既知の未実装・保留

- 出力設定の表示項目ON/OFF・ロゴ画像・1ページの日数/講師列数・生徒別改ページ方式は引き続き未実装（v0.3.2から変更なし）。
- ⑤の多重近傍探索は、データ規模によっては改善が見られない場合がある（CP-SATが証明済み最適解に早期到達する場合、探索回数を増やしても結果は変わらない）。

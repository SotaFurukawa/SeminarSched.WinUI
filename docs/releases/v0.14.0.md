# v0.14.0 (beta)

Status: Draft Release。新機能のためminorを上げ、patchを0へ戻してv0.14.0とした。

## 新機能: 自動作成の探索方針（優先度）を校舎ごとに変更可能にした

- これまで、自動作成（CP-SATソルバー）が7つの探索方針
  （生徒の授業日・講師の出勤日・1コマあたりの対応人数・同一講師×同一生徒の連続コマ・
  一日あたりの講師人数・講師ごとのコマ数の偏り・時間帯）のどれを優先するかは、
  コード内に固定された重み（暗黙の優先順位）で決まっており、校舎ごとに変更できなかった。
- ①設定＞⑦最適化探索の方針設定画面に「探索方針（優先度の高い順）」の並び替えUIを追加した。
  各行にカーソルを合わせると右端に▲▼が表示され、クリックで優先順位を入れ替えられる。
  左端の番号も並びに応じて自動的に振り直される。
  「考慮しない」以外の値を選ぶと、その方針が自動的に一番上へ移動する。
- デフォルトの優先順位は、これまでの固定重みが実際に作っていた優先順位
  （生徒の授業日＞講師の出勤日＞1コマあたりの対応人数＞同一講師×同一生徒の連続コマ＞
  一日あたりの講師人数＞講師ごとのコマ数の偏り＞時間帯）をそのまま再現しており、
  既存プロジェクトの自動作成結果に影響はない。
- 優先順位はプロジェクトDBの`SchedulingPolicy`テーブルに保存され、
  プロジェクトを開き直しても保持される。
- `CpSatScheduleSolverTests`に、優先順位の入れ替えが実際にソルバーの選択を変えることを
  直接検証する回帰テストを追加した。

出力設定タブ右の「＋（新規タブ追加）」ボタンは不要なため非表示にした。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

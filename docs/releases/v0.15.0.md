# v0.15.0 (beta)

Status: Draft Release。新機能のためminorを上げ、patchを0へ戻してv0.15.0とした。

## 新機能: プロダクトキーによるライセンス認証

- アプリの初回起動時（または、前回認証した年度が2月1日のロールオーバーで切れた場合）に、
  プロダクトキーの入力を要求するダイアログを表示するようにした。入力されたキーが正しくない
  場合は、ダイアログを閉じずにその場でエラーを表示し、再入力できる。認証せずに終了することも
  できる（「終了」ボタン）。
- プロダクトキーは年度（毎年2/1〜翌1/31）ごとに有効なものと、永久に有効な「マスターキー」の
  2種類がある。認証に成功すると、アプリ名「ShikiWari」の横に「2026年版」（マスターキーの
  場合は「完全版」）と表示される（ウィンドウタイトル・タイトルバー・アプリ情報画面）。
  設定画面にも現在のライセンス状態を表示する。
- 検証はオフラインで完結する（ユーザーの明示判断により、現時点では使い回し・解析への耐性は
  重視していない。正式リリース後に強化する）。プロダクトキーの生成は新設した
  `tools/SeminarSched.ProductKeyTool`（コンソールツール）で行う:
  `dotnet run --project tools/SeminarSched.ProductKeyTool -- 2027`
  `dotnet run --project tools/SeminarSched.ProductKeyTool -- master`
- 設計判断の詳細は[docs/adr/0006-product-key-licensing.md](../adr/0006-product-key-licensing.md)
  を参照。

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

# v0.11.1 (beta)

Status: Draft Release。ユーザー報告「設定タブだけ全部グレー表示になり操作できない」「⑤の進捗表示を
円形のゲージにしてほしい」「v0.9.1からGitHub Releaseにassetが付いていない」（checkpoint 109）への
対応。不具合修正・UI変更のためNext Version Ruleの既定に従いv0.11.1とした。

## ハイライト

- 「①設定」タブが、状況によっては開いても内容が全部グレー表示になり操作できなくなる不具合を修正
  した（プロジェクトを開く前に一度①設定を開くと、その後プロジェクトを開いても直らないまま
  になっていた）。
- ⑤時間割自動作成の進捗表示を、円形のゲージ（中央に進行パーセンテージのみを表示）へ全面的に
  変更した。段階名・戦略名・残り時間のテキストは表示しなくなった。
- v0.9.1〜v0.11.0のDraft Releaseに、インストーラー（msix・Setup.exe・証明書）が付いていなかった
  問題を修正し、4バージョン分すべてに追加した。

## 主な変更点

- `SetupPage.xaml.cs`の`Page_Loaded`成功パスに、以前は欠けていた`Tabs.IsEnabled = true`を追加した。
- `OptimizationPage`の進捗表示を`ProgressRing`の決定的モード（中央にパーセンテージのTextBlockを
  重ねる）へ置き換え、段階/戦略名・残り時間のテキスト表示を削除した。

## 既知の未実装・保留

- 品質プロファイル（`OptimizationProfileCatalog`）のハードウェアtier閾値較正は、実機フィードバック
  次第で今後調整の可能性がある（v0.11.0参照）。
- 今回の設定タブの修正・円形ゲージの見た目は、この開発機では実際の画面を確認できないため、実機での
  ご確認をお願いしたい。

詳細は[機能同等性台帳](../FEATURE_PARITY.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

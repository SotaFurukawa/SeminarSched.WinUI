# v0.29.2 (beta)

Status: Draft Release。「少し時間を要しています」警告の表示条件を変更するpatch。

## 変更内容

- **時間割自動作成の「少し時間を要しています」警告が表示されるタイミングを早めた**: 従来は
  品質設定で決まる名目の持ち時間をすべて使い切るまで一切表示されなかった。今回から、経過時間が
  その名目の持ち時間（想定の最大値）の66%に達した時点で、進捗がその経過割合に追いついていなければ
  警告を表示するようにした。それ以降も、経過時間の割合と進捗の割合を継続的に比較し、進捗が
  追いついていない間は警告を表示し続ける。

## 検証について

既存の全テスト（計256件）がすべて通過することを確認済み。バックエンドの探索ロジック自体は
変更していないため、自動作成の挙動そのもの（延長探索を行うかどうか等）に影響は無い。

表示タイミングについては、ビルド成功とコードレベルの確認のみ行い、実機（dev-run）での画面確認は
このバージョンでは行っていない。**次回パソコンを使用する際に、時間のかかる自動作成を実行し、
経過時間が名目の持ち時間の66%を超えた頃に、進捗が遅れていれば「少し時間を要しています」の警告が
表示されることを確認していただきたい。**

詳細は[docs/CODEX_HANDOFF.md](../CODEX_HANDOFF.md)を参照。

このversionのGitHub ReleaseはDraftとして作成する。

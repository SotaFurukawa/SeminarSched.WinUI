# v1.5.6

Status: Release

## 変更内容

### 1. 共通名簿Excelが反映・学年繰り上げ後に消えてしまう不具合の修正

ユーザー報告「以前フォルダが開けないという問題がクライアントで発生していると話したが、そもそも
指定された場所にフォルダがない状態であった。基本情報などが取り込まれてはいるが、xlsxなどが
存在しなくなっていたりします」から見つかった不具合。

`SharedRosterStore`の`ApplyImportAsync`（基本情報xlsxの反映）・`AdvanceStudentGradesAsync`
（学年繰り上げ）は、DBを更新したあと共通名簿Excel（`生徒・講師_基本情報.xlsx`）を削除するだけで、
再生成は次に「Excelで編集」を開いたとき（`EnsureWorkbookAsync`）まで遅延させていた。「編集中の
古い内容を残さない」ための削除だったが、その後一度も「Excelで編集」を開かなければファイルが
存在しないまま放置され、「反映・繰り上げ自体は成功しているのに共通名簿Excelが見当たらない」と
いう状態になっていた。

削除だけで済ませず、その場で直ちに最新のDB内容からExcelを再生成するよう修正した。これにより、
反映・学年繰り上げの直後から常にExcelファイルが存在し、最新のDB内容と一致する。

### 2. 設定ページにアンインストールボタンを追加

ユーザー要望「こういう不具合が発生したときのためにアンインストールボタンを追加したい」への対応。
「設定」ページの「アップデート」の下に「アンインストール」の見出しとボタンを追加した。

ボタンを押すと確認ダイアログ（プロジェクトファイルや共通名簿等のデータは削除されない旨を明記）を
表示し、承認するとインストーラー（Inno Setup）がWindowsの「アプリと機能」へ登録した標準の
アンインストーラーを起動する。アプリ本体のアンインストール処理自体は従来通りインストーラー側が
行うため、挙動は「アプリと機能」から手動でアンインストールする場合と同じ。

- `dotnet build`成功（警告・エラー0件）。

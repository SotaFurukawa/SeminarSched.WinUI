# v1.4.1

Status: Release

## 変更内容

v1.4.0で追加した「中学受験と中学受験以外を分ける」オプションの置き場所を修正した。

- ユーザーから、ホーム画面「新しい講習プロジェクト」の「オプション機能」パネル（「集団授業の
  日程を考慮する」「一人の講師が同時に担当できる生徒数」がある場所）のスクリーンショットと
  ともに「チェックボックスはここに作ってほしいです」という指摘があった。
- 「2 アンケート作成」ページにあったその場限りのチェックボックスを削除し、代わりにホーム画面の
  「一人の講師が同時に担当できる生徒数」のすぐ下に、プロジェクト作成時の設定として
  チェックボックス「中学受験と中学受験以外を分ける」を追加した。
  - 「集団授業の日程を考慮する」と同じく、**プロジェクト作成時だけで決まり、後から変更
    できない**設定にした（既に配布済みのフォームとの一貫性を壊さないため）。
  - 「2 アンケート作成」ページには、現在のプロジェクトの設定値（オン/オフ）をそのまま
    表示するだけの案内文を追加した。
- 機能自体（オンのときに小学生の回答者へ専用の質問を追加し、算数・国語の選択肢をまとめる、
  アプリへ取り込まれる内容は変わらない）はv1.4.0から変更していない。

## 検証について

- `dotnet build`成功（警告・エラー0件）。
- 既存の全テスト（273件）に加え、プロジェクト作成→再読込でこの設定値が保たれることを確認する
  テスト2件を追加し、合計275件がすべて通過することを確認済み。
- `HomePage.xaml.cs`の`BuildDefinition()`で引数を1つ挿入したことに伴い、既存の
  `OtherSeasonNameBox.Text`（講習区分の名称）が誤った引数位置に渡ってしまう事故を防ぐため、
  当該呼び出しを名前付き引数へ修正した（ビルドは通るがテストでは検出できない種類の不具合
  だったため、目視で確認し修正した）。
